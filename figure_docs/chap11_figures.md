## chap11_fig1.png

**背景**：第11章"注意力机制：Q、K、V 从何而来"与"注意力的数学本质（注意力 = 核回归）"。

**意图**：用一个真实训练出来的小例子给出非平凡的注意力权重：模型学会了"相位相近的时刻互相关注"，并借此把噪声平均掉。

**生成方法**：
- 数据：含噪正弦 $x_t = \sin(2\pi t/16 + \phi) + \varepsilon_t$，序列长 $T = 48$（3 个周期），$\varepsilon_t \sim \mathcal{N}(0, 0.3^2)$，每条序列相位 $\phi$ 随机
- 特征：延迟嵌入 $f_t = (x_t, x_{t-1}, x_{t-2}, x_{t-3})$（它决定了该时刻的"相位"）
- 模型：单层单头自注意力，$q_t = W_q f_t$，$k_t = W_k f_t$，$v_t = w_v\cdot f_t + b$，$d_k = 8$，$\alpha_{tj} = \mathrm{softmax}_j(q_t\cdot k_j/\sqrt{d_k})$，$y_t = \sum_j \alpha_{tj} v_j$；没有位置编码，注意力完全由内容决定
- 训练：目标为无噪声的 $\sin$，MSE 损失，Adam（lr $5\times10^{-3}$），batch 128，2000 步；测试序列用固定种子 123
- (a) 测试序列的含噪输入、真值与注意力输出；(b) 注意力矩阵 $\alpha_{ij}$（行归一化）热图，`interpolation='nearest'`；(c) 查询位置 $t = 24$ 那一行的条形图，同相位位置 $j = 8, 24, 40$ 标红

**数据来源**（脚本输出）：
- 训练 MSE 约 0.05；测试序列：输入噪声 MSE 0.0905 → 注意力输出 MSE 0.0356；512 条测试序列：0.089 → 0.047
- 查询 $t = 24$ 的注意力：最大权重 0.14（均匀分布为 $1/48 = 0.021$）；落在与 $t = 24$ 相位差 $\pm 3$ 以内的位置上的权重合计 0.95

**思路（这张图想让读者看到什么）**：
1. 注意力就是"按相似度加权平均"：这里相似度 = 相位是否相同，加权平均 = 去噪。
2. (b) 里周期为 16 的斜条纹不是设计出来的，而是从数据里学出来的——$W_q, W_k$ 把延迟嵌入变成了"相位"，$q\cdot k$ 变成了相位差的余弦。
3. 这正是正文的"注意力 = softmax 核回归"：核由 $q\cdot k$ 定义，$v$ 是被平均的观测值；输出比输入干净一倍。

**读图指南（先看哪、再看哪）**：
- 先看 (a)：灰点是含噪输入，黑线是真值，蓝线是注意力输出；红色虚线是查询位置 $t = 24$，两条红色点线是与它同相位的 $t = 8, 40$。
- 再看 (b)：每一行有 3 个亮块，对应 3 个同相位的周期；亮块排成平行于对角线的条纹，间距正好 16。
- 最后看 (c)：第 24 行的权重集中在 8、24、40 三簇附近，三簇之和接近 1，其余位置几乎为 0；灰色点线是均匀分布的高度。

## chap11_fig2.png

**背景**：第11章"位置编码：告诉模型顺序"，正弦位置编码公式 $PE_{(pos,2i)} = \sin(pos/10000^{2i/d})$，$PE_{(pos,2i+1)} = \cos(\cdot)$。

**意图**：(a) 编码矩阵本身；(b) 各维度是不同波长的正弦；(c) 位置之间的点积只依赖相对位置。

**生成方法**：
- $d_{\text{model}} = 16$，位置 $0..63$，base 10000（选小的 $d$ 是为了让每一列的条纹在 64 个位置内看得清，避免旧图里的混叠）
- (a) `imshow(PE, interpolation='nearest')`，行 = 位置、列 = 维度，色带 $[-1, 1]$
- (b) 维度 $d = 0, 2, 4, 6$（波长 6.3、20、63、199）的连续正弦曲线，叠加整数位置上的采样点
- (c) $S = PE\,PE^\top / (d/2)$，对角线归一化为 1，`imshow(..., interpolation='nearest')`

**数据来源**（脚本输出）：
- 8 个维度对的波长：6.3, 20, 63, 199, 628, 1987, 6283, 19869
- $S$：对角线 1.00，相邻位置 0.94，相隔 8 为 0.59，相隔 32 为 0.44
- Toeplitz 检验 $\max |S_{i,j} - S_{i+1,j+1}| = 6\times10^{-16}$（点积只与 $pos - pos'$ 有关）

**思路（这张图想让读者看到什么）**：
1. 低维高频、高维低频：(a) 左边的列条纹密，右边的列在 64 个位置内几乎不变。
2. 一个位置的编码 = 一组不同频率的"时钟指针"，任意长度都能直接算出来，不需要学习。
3. (c) 的矩阵沿对角线平移不变（Toeplitz），说明 $PE_{pos}\cdot PE_{pos'}$ 只与相对位置有关——注意力可以由此"读出"相对距离，这也是正文说的"$PE_{pos+k}$ 是 $PE_{pos}$ 的线性变换"的体现。

**读图指南（先看哪、再看哪）**：
- 先看 (a)：从左到右条纹由密到疏。
- 再看 (b)：四条曲线的波长与 (a) 对应的列一一对应；点是整数位置的采样值。
- 最后看 (c)：沿对角线的深色带（相邻位置最相似），以及平行于对角线的条纹（相隔一个波长时相似度回升）。
