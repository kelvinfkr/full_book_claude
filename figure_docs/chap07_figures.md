# 第7章 图片说明

## chap07_fig1.png

**背景**：第7章"牛顿迭代法求解逆运动学"一节给出了一个手算示例：双连杆机械臂 $L_1 = L_2 = 1$，目标 $x_d = (1.2, 0.9)$，从 $q^{(0)} = (0^\circ, 90^\circ)$ 出发做一步牛顿迭代得到 $q^{(1)} = (-5.7^\circ, 84.3^\circ)$，末端误差从 $0.22$ 缩到约 $0.02$。这张图把同一个例子真正迭代到收敛，放在该示例之后（figure 环境已从"案例总结"处移到 `\end{example}` 之后）。

**意图**：让读者把"每一步解一个线性方程 $J\,\Delta q = e$"与"末端一步步逼近目标"对应起来，看到牛顿法二次收敛有多快，并解释这个例子为什么收敛得如此顺利——目标点离奇异位形很远。

**生成方法**：
- 代码文件：`code/chap07_robotics.py`（从仓库根目录运行 `python3 code/chap07_robotics.py`）
- 使用统一风格模块 `code/textbook_style.py`，同时输出 `figs_chap07/chap07_fig1.{pdf,png}`
- (a) 用正运动学画出 $q^{(0)}$、$q^{(1)}$ 与收敛解 $q^\ast$ 三个姿态，插图放大目标附近
- (b) 牛顿法每一步的末端误差 $\|x_d - f(q^{(k)})\|$，对数轴，标出数值
- (c) 由余弦定理把末端半径 $r$ 映射到 $q_2$，画 $|\det J| = L_1 L_2 |\sin q_2|$ 的圆盘热图，叠加边界 $r=2$、$r=\sqrt{2}$ 圆与收敛姿态
- 脚本同时在终端打印三个只需要数字、不需要图的验证：SVD 投影到 SO(3)、指数映射 vs 欧拉加法、力传递 $\tau = J^\top F = (-20, -10)$ N·m（正文案例）

**数据来源**：
- 全部由脚本真实计算，牛顿迭代序列（脚本输出）：
  - $k=0$：$q=(0^\circ, 90^\circ)$，末端 $(1, 1)$，误差 $2.24\times10^{-1}$
  - $k=1$：$q=(-5.73^\circ, 84.27^\circ)$，末端 $(1.194, 0.880)$，误差 $2.07\times10^{-2}$
  - $k=2$：$q=(-4.54^\circ, 82.83^\circ)$，误差 $2.16\times10^{-4}$
  - $k=3$：误差 $2.38\times10^{-8}$；$k=4$：误差 $2.5\times10^{-16}$
- 收敛解 $q^\ast = (-4.54^\circ, 82.82^\circ)$，$\cos q_2^\ast = 0.125$，与正文余弦定理检验一致
- 正文 tryit 的初值 $(30^\circ, 30^\circ)$：脚本算出第一步 $\Delta q = (-55.8^\circ, 98.9^\circ)$，误差先由 $0.50$ 升到 $0.64$，6 步后收敛

**思路（这张图想让读者看到什么）**：
1. 牛顿法就是"线性化—求解—更新"的循环：(a) 里每一根手臂就是一次更新后的位形，末端沿灰色虚线走向红星。
2. 收敛是二次的：(b) 中误差的指数 $-1, -2, -4, -8$ 每步翻倍，四步到机器精度；线性收敛只会每步减少固定倍数，画在对数轴上是直线，这里是越来越陡的曲线。
3. 收敛快慢由雅可比是否良态决定：(c) 中目标点落在 $|\det J| \approx 0.99$ 的深色区，远离 $r = 2$ 与圆心两处 $\det J = 0$ 的奇异位形。正文 tryit 里换初值 $(30^\circ, 30^\circ)$ 第一步反而变差，是因为初值离解太远、线性化不准，而不是因为奇异。

**读图指南（先看哪、再看哪）**：
- 先看 (a)：浅蓝色 $k=0$ 是"先伸平、再把小臂竖起"的初始姿态，深蓝色 $k=1$ 是一步之后，黑色虚线是收敛解，红星是目标；插图里 $x^{(1)}$ 到目标的距离就是正文算出的 $0.02$。
- 再看 (b)：横轴迭代次数，纵轴对数误差；相邻两点的纵向落差越来越大，这是二次收敛的标志；灰色虚线是双精度机器精度。
- 最后看 (c)：颜色越深越灵活；红色虚线边界与圆心是奇异位形；目标（红星）在 $r = 1.5$，靠近最灵活的 $r = \sqrt{2}$ 点线圆。
