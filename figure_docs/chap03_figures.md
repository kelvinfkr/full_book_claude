# 第3章 图片说明

## brachistochrone.pdf

**背景**：第3章介绍变分法，最速降线是变分法的经典问题。

**意图**：
1. 展示为什么摆线是下滑最快的曲线
2. 对比直线、抛物线、摆线的下滑时间
3. 直观展示Euler-Lagrange方程的物理意义

**生成方法**：
- 代码文件：`code_chap03/chap03_variational.py`
- 参数化摆线方程：x = r(θ - sinθ), y = r(1 - cosθ)
- 数值积分计算下滑时间：T = ∫√[(1+y'²)/(2gy)] dx
- 绑制三种曲线及其下滑时间对比

**数据来源**：
- 起点A(0,0)到终点B(4,-3)
- 重力加速度g = 9.8 m/s²
- 解析解：摆线参数r由边界条件确定

## catenary.pdf

**背景**：悬链线问题是另一个变分法经典问题。

**意图**：
1. 解释为什么悬挂的链条形成双曲余弦曲线
2. 对比悬链线与抛物线的差异
3. 展示势能最小化原理

**生成方法**：
- 代码文件：`code_chap03/chap03_variational.py`
- 悬链线方程：y = a·cosh(x/a)
- 抛物线拟合：y = ax² + c
- 计算两种曲线的势能

**数据来源**：
- 固定两端点的边界条件
- 链条总长度约束
- 参数a由等长约束确定
