## latent_dynamics.png

**背景**：第16章"潜空间动力学：在梦境中学习"。潜空间动力学模型的三件套：感知 $z_t=\text{Encoder}(o_t)$、预测 $z_{t+1}=\text{Dynamics}(z_t,a_t)$、想象 $\hat o_{t+1}=\text{Decoder}(z_{t+1})$；正文随后把潜空间比作"学出来的广义坐标"（第5章用 $\theta$ 而不是 $(x,y)$ 描述单摆）。

**意图**：用一个在 CPU 上两分钟就能训练完的真实实验，把"高维观测 → 低维潜态 → 潜空间里做预测"三步都画出来，并证明学到的二维潜态就是单摆的相空间 $(\theta,\omega)$ 换了一套坐标。

**思路（这张图想让读者看到什么）**：智能体看到的只是 24×24 的带噪图像（1152 维，两帧堆叠），看不到 $\theta$ 和 $\omega$。编码器从单帧学出一个一维坐标 $q$，潜态取 $z_t=(q_t,\,q_t-q_{t-1})$——"位置 + 速度"，与第5章的广义坐标同构；转移模型只学一个"加速度" $a(q,v)$，隐空间里用辛欧拉步进。(b)(c) 并排放置，读者应看到三条不同能量的轨迹在两边都是一组嵌套的闭合环——潜空间与真实相空间之间存在光滑映射（三次多项式回归 $R^2$：$\theta$ 1.000，$\omega$ 0.994）。(d) 则回答"在梦里预测多远还靠谱"：纯隐空间展开 30 步（6 s，约一个周期）后解码，像素误差仍停在观测噪声水平附近，而"保持当前帧不变"的基线误差高 5 倍。训练中的"方差不坍缩"项正是正文第1章回顾框里说的 VICReg 式软约束。

**读图指南（先看哪、再看哪）**：
1. 先看 (a)：这是模型唯一能看到的东西——8 帧带噪的单摆图像（摆锤是一个大高斯斑，摆杆很淡）。
2. 再看 (b)：真实相空间 $(\theta,\omega)$ 里三条不同能量的轨迹（蓝 → 橙 → 紫，能量递增），这是"上帝视角"，模型看不到。
3. 对照 (c)：同样三条轨迹经编码器得到的 $(q_t, v_t)$（实线）也是三个嵌套的闭合环，起点（圆点）位置也对应；虚线是只用起点 $z_0$ 在隐空间里连续展开 59 步的"梦境"轨迹，与实线基本重合，说明转移模型学到了能量守恒式的闭合轨道（最外圈振幅略小，是模型在大角度处的系统误差）。
4. 最后看 (d)：预测步数增加时，隐空间展开后解码的像素误差（蓝）缓慢上升后停在约 0.04，只略高于噪声水平 0.03（红点线）；灰色虚线是"保持当前帧"的基线，半个周期后误差达 0.25。

**生成方法**：
- 代码文件：`code/chap16/chap16_figures_v2.py`（`latent_experiment` 计算，`fig_latent_dynamics` 画图；运行 `python3 code/chap16/chap16_figures_v2.py latent`，CPU 单线程约 2 min；设置环境变量 `CHAP16_CACHE=<目录>` 可缓存结果以便只改版式时不重训）
- 数据：无阻尼单摆 $\ddot\theta=-\sin\theta$，RK4，$\Delta t=0.2$ s，每条轨迹 61 帧；初始 $(\theta_0,\omega_0)$ 在摆动区（能量 $<1.9$）内均匀采样；训练 300 条、测试 40 条轨迹
- 渲染：24×24 灰度图，支点在中心，摆锤为 $\sigma=2.4$ px 的高斯斑（斑点够大，像素均方误差对位置才有梯度），摆杆为三个淡斑；逐像素加 $\sigma=0.03$ 高斯噪声
- 模型：编码器 576→256→64→1（ReLU），解码器 1→64→256→576，加速度网络 2→64→64→1（tanh）；转移 $v'=v+a(q,v)$，$q'=q+v'$
- 损失：单帧重建 + 隐空间展开 12 步后逐帧重建 + 隐空间一致性（权重 10）+ 方差不坍缩 $\max(0,1-\mathrm{std}\,q)^2$（权重 10）+ 隐坐标时间二阶差分平滑（权重 10）；Adam，学习率 $2\times10^{-3}$ 余弦退火到 $5\times10^{-5}$，5000 步，批 48 段
- 评估：测试集从 4 个不同起点各展开 30 步，解码后与无噪真值算像素 RMSE 并平均；基线为"保持当前帧"

**数据来源**：
- 全部由脚本生成（随机种子 0）；无外部数据
- 计算结果：多步预测像素 RMSE 1 步 0.011、10 步 0.038、30 步 0.043（基线 30 步 0.202，噪声 0.03）；$(q,v)\to(\theta,\omega)$ 三次多项式回归 $R^2=(1.000,\,0.994)$；训练用时约 120 s

## differentiable_physics.png

**背景**：可微物理——把物理仿真器写成可微计算图，梯度沿时间反向传播（数学上就是第7章的伴随方程、第8章的反向传播）。本图做的是"系统辨识"：从带噪观测反推物理参数。

**意图**：给出一个真的能跑通的最小例子：弹簧–质点–阻尼系统 $m\ddot x = -kx - c\dot x + u$，用 PyTorch 自动微分穿过 200 步 RK4 积分器，梯度下降同时辨识 $m, k, c$。

**思路（这张图想让读者看到什么）**：仿真器的每一步都是一条等式约束 $x_{t+1} = \Phi(x_t;\phi)$，损失对参数 $\phi$ 的梯度必须"穿过"所有这些约束——这正是伴随变量（乘子）逐步回传的过程。图要让读者看到：(1) 一个故意猜错一倍的初值也能沿梯度走回真值；(2) 损失降到观测噪声方差附近就不再下降——这是能达到的下限；(3) 三个参数在对数轴上各自收敛到虚线（真值）。

**读图指南（先看哪、再看哪）**：
1. 先看 (a)：灰点是带噪观测，黑细线是真实轨迹，橙色虚线是用初始猜测 $(m,k,c)=(2,5,1)$ 仿真出的轨迹（频率、幅度都不对），蓝色实线是辨识后的仿真轨迹，与黑线重合。
2. 再看 (b)：均方误差从 $3.8\times10^{-1}$ 降到 $8.2\times10^{-4}$，约 100 次迭代后贴着灰色点线（噪声方差 $\sigma^2=9\times10^{-4}$）不再下降；早期的锯齿是 Adam 在振荡系统的损失面上"跳台阶"的表现，不是发散。
3. 最后看 (c)：$k$ 从 5 升到 10、$m$ 从 2 降到 1、$c$ 从 1 降到 0.5，分别落到各自颜色的虚线上；用对数轴是为了让相差 20 倍的三个参数能放进同一张图。

**生成方法**：
- 代码文件：`code/chap16/chap16_figures_v2.py`（`fig_differentiable_physics`，运行 `python3 code/chap16/chap16_figures_v2.py physics`，CPU 约 30 s）
- 仿真：RK4，$\Delta t = 0.02$，200 步（4 s），已知外力 $u(t) = 3\sin 2t + 2\sin 5.5t$，初值 $x_0 = 1, v_0 = 0$
- 观测：只观测位置 $x$，加 $\sigma = 0.03$ 高斯噪声
- 优化：参数取对数（保证为正），Adam，学习率 0.05，300 次迭代；损失为位置的均方误差；梯度由 `torch.autograd` 沿整段 RK4 反向传播

**数据来源**：
- 真实参数 $m=1, k=10, c=0.5$；初始猜测 $m=2, k=5, c=1$
- 计算结果：第 100 次迭代 $m=0.984, k=9.857, c=0.500$；第 300 次 $m=0.993, k=9.922, c=0.502$；最终损失 $8.2\times10^{-4}$（噪声方差 $9\times10^{-4}$）

## cbf_controller.png

**背景**：第16章"具身智能：约束从等式变成不等式"。控制屏障函数（CBF）把"永远安全"写成不等式约束 $h(x)\ge 0$，安全滤波器是一个 QP：在满足 $\dot h \ge -\alpha h$ 的控制里选离标称控制 $u_{\rm ref}$ 最近的那个。正文给出闭式解 $u^* = u_{\rm ref} + \lambda^*(L_g h)^\top$，$\lambda^* = \max\{0, -(L_f h + L_g h\,u_{\rm ref} + \alpha h)/\|L_g h\|^2\}$。

**意图**：用一个可以完全算出来的例子，让读者同时看到三件事——轨迹绕开了障碍、$h$ 始终非负、乘子 $\lambda^*$ 只在约束"顶到边界"时才非零。

**思路（这张图想让读者看到什么）**：本章的 $\lambda$ 是"安全约束的影子价格"。远离障碍时约束不紧，$\lambda^*=0$，滤波器什么都不做（$u^*=u_{\rm ref}$）；一旦 $u_{\rm ref}$ 会把 $h$ 压得太快，$\lambda^*$ 变正，把控制沿 $\nabla h$ 推开——这就是第1章的互补松弛 $\lambda^* \cdot(\text{约束余量})=0$ 在时间轴上的样子。(a) 里在 $\lambda^*$ 最大处画出了向量分解 $u^* = u_{\rm ref} + \lambda^*\nabla h$，让公式和图形对上。

**读图指南（先看哪、再看哪）**：
1. 先看 (a)：红色虚线是不加滤波的直线，穿过淡红色禁区；蓝色实线是 CBF 滤波后的轨迹，贴着绿色安全边界 $h=0$ 滑过去；橙色加粗的一段是 $\lambda^*>0$ 的区段——只有这一段滤波器在起作用。
2. 再看 (b)：无滤波时 $h$ 掉到负值（进入禁区），CBF 滤波后 $h$ 在 0 之上触底回升，从未穿越虚线。
3. 最后看 (c)：$\lambda^*(t)$ 是一个单峰——进入约束前为 0，贴边时升起，离开后归零。对照 (a) 的橙色区段，$\lambda^*>0$ 的时间窗正是轨迹贴边的那一段。

**生成方法**：
- 代码文件：`code/chap16/chap16_figures_v2.py`（`fig_cbf_controller`，运行 `python3 code/chap16/chap16_figures_v2.py cbf`）
- 单积分器 $\dot x = u$（$f=0$，$g=I$），障碍函数 $h(x)=\|x-x_{\rm obs}\|^2-r^2$，$\nabla h = 2(x-x_{\rm obs})$
- 标称控制：朝目标方向、速度 1（离目标 0.1 以内按比例减速以免抖振）
- 每步用闭式解算 $\lambda^*$ 与 $u^*$，前向欧拉 $\Delta t=0.01$ 积分；对二次型 $h$ 可证明离散步也保持 $h>0$
- 绘图统一使用 `code/textbook_style.py`

**数据来源**：
- 起点 $(0,0)$，目标 $(10,10)$，障碍中心 $(5,4)$、半径 $d=1.5$，$\alpha=1$
- 障碍中心故意不放在起点—目标连线上：若三点共线，$u_{\rm ref}$ 与 $\nabla h$ 反向，滤波只会把速度减到零而不会绕行（旧图的 $(5,5)$ 配置正是这种退化情形）
- 计算结果：无滤波 $\min h=-1.75$；CBF 滤波 $\min h=0.106>0$；$\lambda^*>0$ 的时间窗 $t\in[3.71, 7.64]$ s，$\max\lambda^*=0.181$；到达目标用时 15.3 s（直线 14.1 s）

## multi_obstacle.png

**背景**：同一个 CBF 安全滤波器推广到多个障碍：每个障碍一条不等式约束 $h_i(x)\ge 0$，QP 同时满足所有约束，每条约束有自己的乘子 $\lambda_i$。

**意图**：展示多约束 CBF-QP 的解，并把每条约束的 $\lambda_i(t)$ 单独画出来，回答"哪个约束在何时活跃"。

**思路（这张图想让读者看到什么）**：多约束时 KKT 条件是 $u^* = u_{\rm ref} + \sum_i \lambda_i \nabla h_i$，$\lambda_i \ge 0$，$\lambda_i\,(\cdots)_i = 0$。图 (b) 就是这组互补松弛条件的时间轴版本：三条 $\lambda_i(t)$ 大部分时间为零，只有轨迹贴近第 $i$ 个障碍时 $\lambda_i$ 才升起；穿过障碍 1、2 之间的缝隙时两条 $\lambda$ 同时非零——两个"斥力"叠加，把轨迹夹在缝隙中间。

**读图指南（先看哪、再看哪）**：
1. 先看 (a)：红色虚线是直线参考路径，会撞上障碍 3、擦过 1 和 2；蓝色实线是滤波后的轨迹。轨迹上按障碍颜色标出的点表示该约束活跃（$\lambda_i>0$）——穿缝隙那一段是橙色光环套紫色内核，说明 1、2 同时活跃；绕障碍 3 那一段是青色。
2. 再看 (b)：三条 $\lambda_i(t)$。灰色阴影是两个约束同时活跃的时间窗（约 1.7 s）；随后只有 $\lambda_3$ 有一个大得多的峰——因为障碍 3 正挡在路线上，需要更大的修正才能绕过。
3. 对照 (a)(b)：$\lambda$ 的峰值大小反映"这条约束有多碍事"，这正是影子价格的含义。

**生成方法**：
- 代码文件：`code/chap16/chap16_figures_v2.py`（`fig_multi_obstacle`，运行 `python3 code/chap16/chap16_figures_v2.py multi`）
- 多约束 QP：$\min \tfrac12\|u-u_{\rm ref}\|^2$ s.t. $\nabla h_i^\top u + \alpha h_i \ge 0$；由于只有 3 条约束，直接枚举活跃集求 KKT 点（严格凸 QP 的解唯一），得到精确的 $u^*$ 与 $\lambda_i$
- 单积分器、前向欧拉 $\Delta t = 0.01$，标称控制同 cbf_controller

**数据来源**：
- 起点 $(0,0)$，目标 $(10,10)$，$\alpha = 1$
- 障碍 1：中心 $(3.1, 5.0)$、半径 1.2；障碍 2：$(5.0, 3.1)$、半径 1.1（两者夹出一条宽约 0.4 的缝隙，正对直线路径）；障碍 3：$(7.6, 7.9)$、半径 1.3（直接挡在直线上）
- 计算结果：各约束 $\min h_i = 0.46, 0.50, 0.020$（全部 $>0$）；$\max\lambda_i = 0.133, 0.135, 0.313$；两约束同时活跃 170 步（1.7 s）；到达用时 17.6 s

## unified_view.png

**背景**：本章小结"全书三问"——目标是什么？约束是什么？$\lambda$ 代表什么？——以及附录"一条主线"总表。这是一张**概念示意图**，不含计算数据。

**意图**：把 $\mathcal L = f + \lambda^\top g$ 在各章的化身画成一张关系图：中心是统一的拉格朗日函数与 KKT 条件，两侧 8 个框写出该章的目标 $f$、约束 $g$、$\lambda$ 的身份与一阶条件。

**思路（这张图想让读者看到什么）**：全书只有一条主线。读者应当看到每个框的三行内容都能填进同一个模板，而变化的只是名字：$\lambda$ 在第1章叫影子价格，第3章叫广义动量，第6–7章叫协态变量/接触力，第8章叫误差信号，第9章叫值函数，第14章叫损失权重，第10章叫均衡价格，第16章叫安全约束的价格。中心框下方的一句话"$\lambda$ 的身份随章节变化，结构从未改变"就是全书的结论。

**读图指南（先看哪、再看哪）**：
1. 先看中心：$\mathcal L = f + \lambda^\top g$，"目标 + 价格 × 约束"，下面是 KKT 条件（驻点、非负、互补松弛）。
2. 再看中心上方的三问，它们对应每个侧框的三行：黑色"目标 $f$"、绿色"约束 $g$"、红色"$\lambda$"。
3. 然后沿左列（物理与控制：第1、3、7–8、16章）与右列（学习与博弈：第8、9、14、10章）逐框读，重点比较红色那一行——$\lambda$ 的身份。
4. 每个框底部的灰字是该章的一阶条件（KKT、欧拉–拉格朗日、伴随方程、反向传播、贝尔曼方程……），它们都是 $\partial\mathcal L/\partial x = 0$ 的具体形式。

**生成方法**：
- 代码文件：`code/chap16/chap16_figures_v2.py`（`fig_unified_view`，运行 `python3 code/chap16/chap16_figures_v2.py unified`）
- matplotlib 按英寸坐标排版圆角框、母线式连线与箭头；全部中文，公式用 mathtext

**数据来源**：
- 概念性示意图；各框内容取自 `chapters/appendix_index.tex` 的"一条主线：各章的目标 / 约束 / $\lambda$"总表与第16章小结
