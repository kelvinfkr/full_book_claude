## chap08_fig1.png

**背景**：第8章正文"深度学习训练的完整流程"之后的代码演示：用自制的标量自动微分引擎 `Variable`（约 80 行）完成前向传播、反向传播和参数更新，并把反向传播与最优控制的伴随方程放到同一张图里。

**意图**：(a) 验证自动微分给出的导数；(b)(c) 用它训练一个神经元；(d) 用一个可计算的小例子展示"反向传播的伴随量 δ_i 就是离散化的协态 p(t)"。旧版第 4 面板是一段文字表格，不是图，已替换。

**生成方法**：
- 代码文件：`code/chap08_autograd.py`（同一份副本在 `code/chap08/chap08_autograd.py`），输出 `figures/chap08/chap08_fig1.{pdf,png}`
- (a)：`x = Variable(3.0); y = x*x + 2*x + 1; y.backward()`，用 `x.grad` 画切线
- (b)(c)：4 个样本的线性回归 y ≈ 2x，学习率 0.01，梯度下降 100 步
- (d)：把 N 层残差网络 z_{i+1} = z_i + h·tanh(W(t_i) z_i + b(t_i))（h = T/N，T = 2，状态二维）看成前向 Euler 离散的最优控制问题，终端损失 ℓ = ½‖z_N − z*‖²；用 `Variable` 引擎反向传播，读出每一层 z_i 的 `.grad`，即 δ_i = ∂ℓ/∂z_i。连续协态 p(t) 用 `solve_ivp`（rtol=1e-10）先正向积分 x(t)，再反向积分伴随方程 ṗ = −(∂f/∂x)ᵀp，p(T) = x(T) − z*。插图：max_i |δ_i − p(t_i)| 随 h 的双对数图与拟合斜率

**数据来源**：
- (a) 自动微分斜率 8.0（解析 2x + 2 = 8）；(b)(c) 训练后 w = 1.948，b = 0.173
- (d) W(t) = [[−0.4, −1.2 − 0.8t], [1.5, −0.2]]，b(t) = (0.3 sin(πt), 0)，z₀ = (1, 0.5)，z* = (−0.5, 1)；
  max|δ_i − p(t_i)|：N = 10 → 0.17，N = 40 → 0.043，N = 160 → 0.011，拟合斜率 1.03（一阶收敛，与前向 Euler 一致）
- 符号约定：书中 λ_i = −δ_i、λ_n = −∇ℓ；图中直接画 δ_i 与 p(t)（p(T) = ∇φ），两者同号

**思路（这张图想让读者看到什么）**：反向传播不是深度学习独有的技巧——把层数当作时间，δ_i 就是最优控制里的协态；层数越多（h 越小），离散的 δ_i 越贴近连续的 p(t)，偏差按 O(h) 缩小。

**读图指南（先看哪、再看哪）**：(a)→(b)→(c) 是"求导→用导数训练→训练结果"的顺序；(d) 先看黑线（连续协态）与蓝点（N = 40）几乎重合，再看橙色方块（N = 10）系统性偏离，最后看插图确认偏差随 h 线性下降。

## computation_graph.pdf

**意图**：用同一张节点布局画出单层神经元 a = σ(Wx + b) 的前向传播（上）与反向传播（下），并突出 σ'(z) 是控制梯度回流的"阀门"。

**生成方法**：

- (a) 蓝色箭头：x、W → × → + （与 b）→ z → σ → a → L（虚线框，表示损失来自后续网络）
- (b) 红色箭头：从 ∂L/∂a 出发，经 ×σ'(z) 得到 ∂L/∂z，再分别流向 W（×xᵀ）、x（Wᵀ×）、b（×1）

**数据来源**：

**思路（这张图想让读者看到什么）**：反向传播就是把前向图的箭头全部反过来、每条边乘上局部导数；所有梯度都要经过 σ'(z) 这一道闸门，它小了什么都流不回去。

**读图指南（先看哪、再看哪）**：先从上图左到右读一遍前向公式；再从下图右到左读，注意每条红色箭头上的"× 什么"；最后停在 σ 节点旁的注记，回想 gradient_flow 中 Sigmoid 的 0.25。

## gradient_flow.pdf

**背景**：扩展阅读"梯度消失问题"一节。

**意图**：(a) 三种激活函数的导数分布；(b) 真实的深层网络中梯度范数随层数的衰减；(c) 真实训练实验中的"死亡 ReLU"。旧图的 (b)(c) 都是用 0.25ⁿ、0.98ⁿ 之类的公式画出来的示意曲线，已改为真实计算。

**生成方法**：
- 代码文件：`code/chap08/activation_functions.py`（依赖 torch，CPU；脚本内固定单线程）
- (a)：解析导数，填充区域；标注 Sigmoid 导数最大值 0.25
- (b)：20 层、宽 64 的全连接网络，随机输入 256 个样本，损失取 ‖h_L‖²；对每层激活值 `retain_grad()` 后反向传播，画 ‖∂L/∂h_{L−k}‖/‖∂L/∂h_L‖（5 个随机种子平均）。Sigmoid / Tanh / ReLU 用 Xavier 初始化，另加一条 ReLU + He 初始化；灰色点线为 0.25^k 参考
- (c)：3 隐藏层×64 的 MLP 回归 sin(2x)cos(2y)（512 个样本，Adam，batch 64，150 epoch）；每个 epoch 统计"在整个训练集上预激活恒 ≤ 0 的隐藏单元"比例（ReLU 下这些单元输出恒为 0、梯度恒为 0，即死亡；Leaky ReLU 下同样的统计量仍有梯度、可以恢复）。4 个随机种子，实线为均值，阴影为最小–最大范围

**数据来源**：
- (b) 距输出 20 层处的梯度范数比：Sigmoid 3×10⁻¹³（≈0.25²⁰），Tanh 0.4，ReLU+Xavier 6.7×10⁻³，ReLU+He 6.8
- (c) 死亡单元比例：ReLU（lr = 0.03）10% → 57%，Leaky ReLU（lr = 0.03）8% → 34%，ReLU（lr = 0.001）10% → 11%

**思路（这张图想让读者看到什么）**：(a) 是原因，(b) 是后果——Sigmoid 每层最多乘 0.25，20 层后梯度只剩 10⁻¹³，实测正好落在 0.25^k 参考线上；ReLU 能否保持梯度还取决于初始化（Xavier 会以 1/√2 每层衰减，He 初始化才守恒）。(c) 说明 ReLU 的另一种失效方式：学习率偏大时一半以上的单元被推到永远不激活的区域且再也回不来，学习率小或改用 Leaky ReLU 都能缓解。

**读图指南（先看哪、再看哪）**：先看 (a) 蓝色曲线的高度（0.25）；再看 (b) 蓝线与灰色点线重合、绿线与红色虚线接近水平；最后看 (c)：红色实线在头几个 epoch 内跳到 50% 以上并保持不变（死了就不再活），橙色虚线来回波动（还能恢复），红色点线几乎不变。

## gradient_check.pdf

**背景**：扩展阅读"梯度检验：验证你的实现"一节。

**意图**：展示解析梯度与中心差分数值梯度的重合程度，并把误差本身画在对数坐标上。

**生成方法**：
- 代码文件：`code/chap08/activation_functions.py`
- 上排 (a)(b)(c)：Sigmoid / Tanh / Swish 的解析导数（蓝色实线）与数值导数 [f(x+ε) − f(x−ε)]/(2ε)（红色虚线），ε = 1e−5，x ∈ [−3, 3] 取 301 点
- 下排：|解析 − 数值| 的绝对误差（绿色填充，对数坐标），标注最大值

**数据来源**：
- 最大绝对误差：Sigmoid 1.1×10⁻¹¹，Tanh 3.3×10⁻¹¹，Swish 3.4×10⁻¹¹
- 这个量级由中心差分的截断误差 O(ε²) 与舍入误差 O(10⁻¹⁶/ε) 共同决定，ε = 1e−5 附近两者相当

**思路（这张图想让读者看到什么）**：梯度检验的"通过"标准不是误差为零，而是误差落在 ε² 与机器精度/ε 决定的水平（约 10⁻¹¹）；如果看到 10⁻⁵ 以上，就是公式写错了。

**读图指南（先看哪、再看哪）**：上排只需确认红蓝两线完全重合；真正的信息在下排——误差在 10⁻¹¹ 附近抖动，且在导数极值点附近（截断误差为零处）出现向下的尖谷。
