# 第1章 图片说明

## kkt_visualization.pdf

**背景**：第1章介绍约束优化与KKT条件，需要可视化展示KKT系统的几何意义。

**意图**：帮助读者直观理解"原点到平面的最短距离"这一经典约束优化问题，展示最优点、约束平面、梯度方向之间的关系。

**生成方法**：
- 代码文件：`code/chap01/chap01_kkt.py`
- 使用matplotlib的3D绑图功能
- 绘制约束平面 x + y + z = 1
- 标注原点、最优点(1/3, 1/3, 1/3)、法向量

**数据来源**：
- 解析解：通过求解KKT线性系统得到
- KKT矩阵为4×4系统，包含Hessian和约束梯度

## shadow_price.pdf

**背景**：介绍拉格朗日乘子的经济学解释——影子价格。

**意图**：展示当约束条件放松时，目标函数值如何变化，验证λ的物理意义。

**生成方法**：
- 代码文件：`code/chap01/chap01_kkt.py`
- 绘制目标函数值随约束参数变化的曲线
- 斜率即为拉格朗日乘子λ

**数据来源**：
- 参数化求解：改变约束 x + y + z = c 中的c值
- 计算对应的最优目标函数值
