\storynote{Richard Sutton}{强化学习之父，与 Andrew Barto 共获 2024 年图灵奖（2025 年公布）。他在1998年合著的教科书《Reinforcement Learning: An Introduction》是该领域的圣经。他的``Bitter Lesson''文章在AI社区引发了深远的讨论。}
在结束这本书之前，我想和你分享一篇2019年震动AI界的短文——Richard Sutton的\textbf{``The Bitter Lesson''}（苦涩的教训）。
\section*{苦涩的教训}
Sutton观察了70年AI发展史，得出一个反直觉的结论：
\begin{quote}
\textit{``过去70年AI研究最重要的教训是：利用计算力的通用方法最终会战胜利用人类知识的方法。''}
\end{quote}
\textbf{例子1：国际象棋}
\begin{itemize}
    \item 1997年Deep Blue击败卡斯帕罗夫，靠的是暴力搜索（每秒2亿步）+ 少量人类知识
    \item 研究者最初试图编码大师的``策略''和``模式''，但这些努力最终被纯粹的搜索力量击败
\end{itemize}
\textbf{例子2：围棋}
\begin{itemize}
    \item 围棋曾被认为需要``直觉''和``模式识别''，纯搜索不可能解决
    \item 2016年AlphaGo用深度学习+蒙特卡洛树搜索击败李世石
    \item 2017年AlphaGo Zero完全不用人类棋谱，从零自我对弈，变得更强
\end{itemize}
\textbf{例子3：语言理解}
\begin{itemize}
    \item 几十年来，NLP研究者手工设计语法规则、词性标注、语义分析……
    \item GPT-3/4用千亿到万亿参数的Transformer+海量数据，``什么都不教''，效果碾压一切
\end{itemize}
\begin{tcolorbox}[colback=red!5, colframe=red!60!black, title=Bitter Lesson的核心]
\textbf{苦涩之处}：研究者花费多年心血设计的``聪明''方法，往往被简单粗暴的``大力出奇迹''方法击败。
\textbf{教训}：
\begin{enumerate}
    \item 计算力会持续增长（摩尔定律），而人类知识的编码很难扩展
    \item 通用的学习和搜索方法（如梯度下降、蒙特卡洛搜索）最终会赢
    \item 我们应该设计能\textbf{利用更多计算}的算法，而不是\textbf{绕过计算}的捷径
\end{enumerate}
\end{tcolorbox}
\section*{这对你意味着什么？}
作为一个刚学完这本书的学生，你可能会问：``既然大力出奇迹，我学这些数学有什么用？''
答案是：\textbf{你学的恰恰是``大力''的基础}。
\begin{itemize}
    \item \textbf{梯度下降}（第8章）是深度学习的引擎
    \item \textbf{贝尔曼方程}（第9章）是AlphaGo的核心
    \item \textbf{变分法}（第3章）是物理信息神经网络的理论基础
    \item \textbf{KKT条件}（第1章）是约束优化的通用语言
\end{itemize}
Bitter Lesson并不是说``数学没用''，而是说``\textbf{通用的数学方法+计算力} > 特定领域的手工设计''。

\begin{itemize}

    \item 用有限元分析一个简单的结构
    \item 复现一篇你喜欢的论文
\end{itemize}
