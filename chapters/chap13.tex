\section*{引言：一个新的求解思路}

\marginnote{PINN由Raissi、Perdikaris和Karniadakis于2019年在Journal of Computational Physics发表，全称Physics-Informed Neural Networks。这篇论文引用量已超过15000次，开创了AI for Science的重要方向。}

\storynote{George Karniadakis}{1961--，布朗大学教授，美国工程院院士，PINN的主要推动者。他的研究横跨计算力学和机器学习，是``科学机器学习''(SciML)领域的奠基人之一。他培养了大量学生推动AI for Science的发展。}

在传统的数值分析课程中，我们学习用有限差分、有限元等方法求解微分方程。这些方法需要将空间离散成网格，然后在网格点上求解代数方程组。

但有没有一种完全不同的思路？

\textbf{物理信息神经网络}（Physics-Informed Neural Networks，简称PINN）提供了一个新视角：与其在网格上逐点求解，不如直接\textbf{学习一个满足物理定律的函数}。

这个想法听起来很简单，但实现起来却充满挑战。本章我们将用熟悉的\textbf{拉格朗日乘子法}来理解PINN的数学本质，揭示它为什么有时很好用，有时却训练不出来，以及现代研究如何解决这些问题。

\vspace{0.3cm}
\noindent\textit{为什么一个连网格都没有的神经网络能"解"微分方程？为什么损失函数里那个不起眼的权重 $\lambda$ 能决定训练成败？为什么同样的网络，换一种写法（能量而不是残差）就只需要一阶导数？}

\begin{quote}
\textbf{本章目标}：让你看清 PINN 不是"神经网络的新玩法"，而是第1章的老朋友：物理定律是约束，神经网络只是一个可微的猜测函数，损失函数里那些让人头疼的权重，就是第1章视角三里的罚系数 $\rho$。看懂了这一点，PINN 为什么会训练失败、自适应权重为什么有效、Deep Ritz 为什么只要一阶导数，都会变成同一个问题的不同侧面。
\end{quote}

\section{从约束优化看PINN}
% ====================================================================================

\subsection{传统数值方法的困境}

考虑一个你在数学物理方程课程中见过的泊松方程（Poisson equation）：
\begin{equation}
    -\nabla^2 u = f, \quad x \in \Omega
\end{equation}
\begin{equation}
    u = g, \quad x \in \partial\Omega
\end{equation}

传统有限元方法求解这个问题需要以下步骤：
\begin{enumerate}
    \item 将区域$\Omega$剖分成$N$个网格单元（三角形或四边形）
    \item 在每个单元上选取基函数，构造$N \times N$的刚度矩阵$\mathbf{K}$
    \item 求解线性方程组$\mathbf{K}\mathbf{u} = \mathbf{f}$
\end{enumerate}

\begin{example}[维数灾难]
假设我们要在一个$d$维立方体$[0,1]^d$上求解泊松方程，每个方向需要$n=100$个网格点。那么：
\begin{itemize}
    \item $d=1$（一维）：需要$100$个网格点
    \item $d=2$（二维）：需要$100^2 = 10^4$个网格点
    \item $d=3$（三维）：需要$100^3 = 10^6$个网格点
    \item $d=4$（四维）：需要$100^4 = 10^8$个网格点
    \item $d=10$（十维）：需要$100^{10} = 10^{20}$个网格点——这比宇宙中的原子数还多！
\end{itemize}

这就是著名的\textbf{维数灾难}（curse of dimensionality）：传统网格方法在高维问题上完全失效。
\end{example}

\subsection{PINN的核心思想}

PINN的想法出奇地简单：

\begin{framed}
\textbf{PINN的核心思想}：用一个神经网络$u_\theta(x)$来近似微分方程的解，其中$\theta$是网络的所有可学习参数（权重和偏置）。
\end{framed}

神经网络有两个美妙的性质：

\textbf{性质1：无网格}。给定任意点$x \in \mathbb{R}^d$，神经网络可以直接输出该点的函数值$u_\theta(x)$，无需事先构建网格。这意味着在高维空间中，我们只需要在感兴趣的点上采样，而不需要覆盖整个空间。

\textbf{性质2：自动微分}。神经网络是由基本运算（矩阵乘法、非线性激活）复合而成的，每一步都是可微的。利用\textbf{自动微分}（automatic differentiation），我们可以精确计算$u_\theta$对输入$x$的任意阶导数：
\begin{equation}
    \frac{\partial u_\theta}{\partial x}, \quad \frac{\partial^2 u_\theta}{\partial x^2}, \quad \nabla^2 u_\theta, \quad \text{等等}
\end{equation}
\review{第9章}{自动微分不是数值差分：它沿计算图逐节点套链式法则，导数是精确的。第9章我们手写过一个微型 autograd；PINN 里的 $\partial^2 u_\theta/\partial x^2$ 就是对同一张计算图"再求一次导"。}

\begin{remark}[自动微分 vs 数值微分 vs 符号微分]


\begin{itemize}
    \item \textbf{数值微分}：$f'(x) \approx \frac{f(x+h) - f(x)}{h}$，简单但有截断误差和舍入误差
    \item \textbf{符号微分}：推导出$f'(x)$的解析表达式，精确但表达式可能爆炸式增长
    \item \textbf{自动微分}：沿着计算图传播导数，既精确又高效。这是深度学习框架（PyTorch、TensorFlow）的核心技术
\end{itemize}

\end{remark}

    \caption{PINN训练流程示意图。输入坐标$(x,t)$经过神经网络得到预测值$u_\theta$，通过自动微分计算所需的导数，然后分别计算PDE损失、边界条件损失和初值条件损失。三种损失加权求和后通过反向传播更新网络参数。}

图\ref{fig:pinn_workflow}展示了PINN的完整训练流程。对于初学者来说，理解这个流程图是掌握PINN的关键：
\begin{enumerate}
    \item \textbf{前向传播}：给定输入坐标，神经网络输出预测的物理量
    \item \textbf{自动微分}：利用计算图，精确计算网络输出对输入的各阶导数
    \item \textbf{损失计算}：将导数代入PDE，计算残差；同时检查边界和初值条件是否满足
    \item \textbf{反向传播}：基于总损失，更新网络参数
\end{enumerate}

但如何保证这个网络"学到"正确的物理？答案是：\textbf{约束优化}。

\subsection{约束优化的视角}

让我们用你在数学分析中学过的拉格朗日乘子法来重新审视这个问题。

我们的目标是找到一个函数$u$，使得：
\begin{align}
    \mathcal{N}[u] &= f \quad \text{在} \quad \Omega \quad \text{内部（PDE约束）} \\
    \mathcal{B}[u] &= g \quad \text{在} \quad \partial\Omega \quad \text{边界上（边界条件）}
\end{align}
这里$\mathcal{N}$是微分算子（比如$\mathcal{N} = -\nabla^2$），$\mathcal{B}$是边界算子（比如$\mathcal{B}[u] = u|_{\partial\Omega}$）。

\begin{example}[回顾有限维拉格朗日乘子法]
考虑有限维优化问题：
\begin{equation}
    \min_{x \in \mathbb{R}^n} f(x) \quad \text{s.t.} \quad g(x) = 0
\end{equation}
拉格朗日函数为：
\begin{equation}
    \mathcal{L}(x, \lambda) = f(x) + \lambda^T g(x)
\end{equation}
最优解满足KKT条件：$\nabla_x \mathcal{L} = 0$，$g(x) = 0$。
\end{example}

对于PINN，如果我们将约束严格写成拉格朗日形式：
\begin{equation}
    \mathcal{L}(u, \lambda, \mu) = \text{（某个目标函数）} + \int_\Omega \lambda(x) (\mathcal{N}[u] - f) \, dx + \int_{\partial\Omega} \mu(x) (\mathcal{B}[u] - g) \, ds
\end{equation}

但在实践中，我们通常不显式引入拉格朗日乘子函数$\lambda(x)$和$\mu(x)$（因为它们也是无穷维的），而是采用更简单的\textbf{罚函数法}——直接惩罚约束违反的程度。

\begin{tcolorbox}[colback=yellow!10, colframe=orange!80, title=本章的核心观点]
\textbf{PINN 就是第1章的拉格朗日乘子法，只是约束从几条变成了"每个配点一条"，而且我们先走的是视角三——罚函数——这条近路。}

这不是比喻。PINN 的"约束"就是物理定律本身：在每个内部配点 $x_i$ 要求 $\mathcal{N}[u_\theta](x_i) - f(x_i) = 0$，在每个边界配点 $x_j$ 要求 $u_\theta(x_j) - g(x_j) = 0$——有多少个配点，就有多少条约束。目标函数则出奇地简单：\textbf{什么都不用优化}（$f \equiv 0$），我们只是在找一个可行点；有观测数据时目标才变成数据误差。固定权重 PINN 的损失 $L_{\mathrm{PDE}} + \rho\, L_{\mathrm{BC}}$ 就是第1章的 $f + \frac{\rho}{2}|g|^2$；自适应权重就是把隐含乘子 $\rho\, g$ 换成显式乘子 $\lambda$ 再做对偶上升；硬约束则是第1章的"代入消元"。

\begin{center}
\renewcommand{\arraystretch}{1.3}
\small
\begin{tabular}{lll}
\toprule
 & \textbf{第1章} & \textbf{本章（PINN）} \\
\midrule
变量 & $x \in \R^n$ & 网络参数 $\theta$（决定函数 $u_\theta$） \\

\bottomrule
\end{tabular}
\end{center}
\end{tcolorbox}
\review{第1章}{视角三"罚函数"：把约束 $g(x) = 0$ 软化成 $\frac{\rho}{2}|g|^2$ 加进目标，$\rho \to \infty$ 时隐含乘子 $\rho\, g(x)$ 趋向真正的 $\lambda$。PINN 损失里的权重就是这个 $\rho$。}

\subsection{PINN的损失函数：罚函数法}

\begin{keyidea}[配点（Collocation Points）是什么？——大白话版]
在传统方法中，我们需要在整个区域建立"网格"，在每个网格点上求解。但PINN使用的是\textbf{配点法}（collocation method）：

\textbf{核心思想}：随机撒一些点，检查神经网络在这些点上是否"正确"。

\begin{itemize}
    \item \textbf{内部配点}$\{x_i^r\}$：在区域$\Omega$内部随机撒的点。我们在这些点上检查：神经网络的输出是否满足微分方程？
    \item \textbf{边界配点}$\{x_j^b\}$：在边界$\partial\Omega$上撒的点。我们在这些点上检查：神经网络的输出是否满足边界条件？
\end{itemize}

\textbf{类比}：想象你是一个老师在批改作业。你不可能检查学生在无穷多个点上的答案，所以你随机抽查几个点。如果这些点都对了，你就认为学生大概率掌握了（当然，抽查的点越多，判断越准确）。

\textbf{为什么叫"配点"？}因为我们要求神经网络的输出在这些点上和正确答案"配"上（match）。
\end{keyidea}

\begin{definition}[PINN损失函数]
PINN的损失函数由两部分组成：
\begin{equation}
    \mathcal{L}_{\text{PINN}}(\theta) = \underbrace{\frac{1}{N_r}\sum_{i=1}^{N_r} \left|\mathcal{N}[u_\theta](x_i^r) - f(x_i^r)\right|^2}_{L_{\text{PDE}}：\text{PDE残差}} + \underbrace{\lambda \cdot \frac{1}{N_b}\sum_{j=1}^{N_b} \left|u_\theta(x_j^b) - g(x_j^b)\right|^2}_{L_{\text{BC}}：\text{边界条件残差}}
\end{equation}
其中：
\begin{itemize}
    \item $\{x_i^r\}_{i=1}^{N_r}$是在区域$\Omega$内部随机采样的\textbf{配点}（collocation points）
    \item $\{x_j^b\}_{j=1}^{N_b}$是在边界$\partial\Omega$上采样的配点
    \item $\lambda > 0$是\textbf{罚参数}（penalty parameter），平衡两个损失项的重要性
\end{itemize}
\end{definition}
\clarify{别把损失权重和拉格朗日乘子混为一谈。第1章的对照：罚系数 $\rho$ 是你定的"罚款单价"，乘子 $\lambda$ 是问题自己算出来的"影子价格"。本章沿用 PINN 文献的习惯把这个权重记作 $\lambda$——请记住它扮演的是 $\rho$ 的角色；只有后面"拉格朗日对偶视角"一节的对偶上升，才真正把乘子请出来。}

\begin{remark}[罚函数法的本质]
回顾第1章视角三的罚函数法：将约束优化问题
\begin{equation}
    \min f(x) \quad \text{s.t.} \quad g(x) = 0
\end{equation}
转化为无约束问题：
\begin{equation}
    \min f(x) + \frac{\rho}{2}\|g(x)\|^2
\end{equation}
当$\rho \to \infty$时，最优解趋近于原问题的解，而隐含乘子 $\rho\, g(x)$ 趋向真正的拉格朗日乘子。

PINN正是这个思路：$L_{\text{PDE}}$惩罚方程不被满足的程度，$L_{\text{BC}}$惩罚边界条件不被满足的程度。
\end{remark}

\begin{tcolorbox}[colback=yellow!10, colframe=orange!50, title=关键洞察]
罚参数$\lambda$的选择至关重要：
\begin{itemize}
    \item $\lambda$太小：边界条件得不到满足，解在边界上偏差很大
    \item $\lambda$太大：梯度被边界项主导，PDE残差下降缓慢
\end{itemize}
这个两难困境是PINN训练困难的核心原因之一，我们将在第\ref{sec:gradient_pathology}节详细讨论。
\end{tcolorbox}
\review{第5章}{有限元处理 Dirichlet 边界的"大数法"也是罚函数：把对角元改成 $10^{20}$ 强迫 $U_0 \approx g_0$，代价是刚度矩阵条件数变差。PINN 里 $\lambda$ 太大导致训练变慢，是同一种病——见第5章扩展阅读"条件数"。}

从图\ref{fig:lambda_effect}中我们可以清楚地看到$\lambda$选择的"甜蜜点"：

\begin{center}
\begin{tabular}{c|cccc}
\hline
$\lambda$ & 1.0 & 10.0 & 100.0 & 1000.0 \\
\hline
最终MSE & $1.56 \times 10^{-6}$ & $6.48 \times 10^{-8}$ & $\mathbf{4.60 \times 10^{-8}}$ & $6.70 \times 10^{-7}$ \\

\end{tabular}

\textbf{实验结论}：
\begin{enumerate}
    \item \textbf{$\lambda=1$太小}：边界损失下降缓慢，最终MSE较大。从解的曲线可以看到，$\lambda=1$的解在边界附近与精确解有明显偏差。

    \item \textbf{$\lambda=10 \sim 100$最优}：在这个范围内，边界条件和PDE都得到了较好的满足，MSE最小。

    \item \textbf{$\lambda=1000$太大}：虽然边界损失很小，但PDE损失收敛缓慢，最终反而损害了整体精度。这是因为梯度被边界项"淹没"，网络无法有效学习内部的PDE行为。
\end{enumerate}

这个实验验证了前面"关键洞察"中的分析：$\lambda$的选择是一个微妙的平衡问题，需要在边界条件和PDE残差之间找到合适的权衡。

\section{手把手实现：一维泊松方程求解器}
% ====================================================================================

现在让我们从最简单的例子开始，完整实现一个PINN求解器。

\subsection{问题设定}

考虑一维泊松方程：
\begin{equation}
    -u''(x) = \sin(\pi x), \quad x \in (0, 1)
\end{equation}
\begin{equation}
    u(0) = 0, \quad u(1) = 0
\end{equation}

\begin{exercise}[title = 解析解推导]
验证这个方程的解析解是$u(x) = \frac{1}{\pi^2}\sin(\pi x)$。

\textbf{提示}：设$u(x) = A\sin(\pi x) + Bx + C$，代入方程和边界条件求解$A, B, C$。
\end{exercise}

\subsection{神经网络架构}

我们使用一个简单的全连接神经网络（Multi-Layer Perceptron，MLP）：

\begin{definition}[全连接神经网络]
一个$L$层的全连接神经网络定义为：
\begin{align}
    h^{(0)} &= x \quad \text{（输入层）} \\
    h^{(l)} &= \sigma(W^{(l)} h^{(l-1)} + b^{(l)}), \quad l = 1, \ldots, L-1 \quad \text{（隐藏层）} \\
    u_\theta(x) &= W^{(L)} h^{(L-1)} + b^{(L)} \quad \text{（输出层，无激活函数）}
\end{align}
其中：
\begin{itemize}
    \item $W^{(l)} \in \mathbb{R}^{n_l \times n_{l-1}}$是第$l$层的权重矩阵
    \item $b^{(l)} \in \mathbb{R}^{n_l}$是第$l$层的偏置向量
    \item $\sigma(\cdot)$是激活函数（如$\tanh$、ReLU等）
    \item $\theta = \{W^{(1)}, b^{(1)}, \ldots, W^{(L)}, b^{(L)}\}$是所有可学习参数
\end{itemize}
\end{definition}

对于我们的问题，我们选择：
\begin{itemize}
    \item 输入维度：$n_0 = 1$（坐标$x$）
    \item 隐藏层：3层，每层50个神经元
    \item 输出维度：$n_L = 1$（函数值$u$）
    \item 激活函数：$\tanh$（光滑，便于求高阶导数）
\end{itemize}

\subsection{完整代码实现}

\begin{lstlisting}[language=Python, caption={PINN求解一维泊松方程的完整代码}]
import torch
import torch.nn as nn
import numpy as np
import matplotlib.pyplot as plt

# ========================
# 第一步：定义神经网络
# ========================
class PINN(nn.Module):
    def __init__(self, layers):
        """
        layers: 每层神经元数量的列表
        例如 [1, 50, 50, 50, 1] 表示输入1维，3个隐藏层各50个神经元，输出1维
        """
        super().__init__()
        
        # 构建网络层
        self.layers = nn.ModuleList()
        for i in range(len(layers) - 1):
            self.layers.append(nn.Linear(layers[i], layers[i+1]))
        
        # 激活函数
        self.activation = torch.tanh
        
        # 参数初始化（Xavier初始化，有助于训练稳定性）
        for layer in self.layers:
            nn.init.xavier_normal_(layer.weight)
            nn.init.zeros_(layer.bias)
    
    def forward(self, x):
        """前向传播"""
        for i, layer in enumerate(self.layers[:-1]):
            x = self.activation(layer(x))
        # 最后一层不加激活函数
        x = self.layers[-1](x)
        return x

# ========================
# 第二步：计算PDE残差
# ========================
def compute_pde_residual(model, x):
    """
    计算PDE残差: -u''(x) - sin(pi*x)
    
    使用自动微分计算二阶导数
    """
    # 确保x需要梯度
    x = x.requires_grad_(True)
    
    # 前向传播得到u
    u = model(x)
    
    # 计算一阶导数 du/dx
    u_x = torch.autograd.grad(
        outputs=u,
        inputs=x,
        grad_outputs=torch.ones_like(u),
        create_graph=True,  # 需要继续求导，所以保留计算图
        retain_graph=True
    )[0]
    
    # 计算二阶导数 d²u/dx²
    u_xx = torch.autograd.grad(
        outputs=u_x,
        inputs=x,
        grad_outputs=torch.ones_like(u_x),
        create_graph=True
    )[0]
    
    # PDE残差: -u'' - f = -u'' - sin(pi*x)
    f = torch.sin(np.pi * x)
    residual = -u_xx - f
    
    return residual

# ========================
# 第三步：定义损失函数
# ========================
def compute_loss(model, x_interior, x_boundary, lambda_bc=100.0):
    """
    计算PINN总损失
    
    参数:
        model: 神经网络模型
        x_interior: 内部配点 (N_r, 1)
        x_boundary: 边界点 (N_b, 1)
        lambda_bc: 边界条件的惩罚权重
    """
    # PDE残差损失
    residual = compute_pde_residual(model, x_interior)
    loss_pde = torch.mean(residual ** 2)
    
    # 边界条件损失: u(0) = 0, u(1) = 0
    u_boundary = model(x_boundary)
    loss_bc = torch.mean(u_boundary ** 2)
    
    # 总损失
    total_loss = loss_pde + lambda_bc * loss_bc
    
    return total_loss, loss_pde, loss_bc

# ========================
# 第四步：训练循环
# ========================
def train_pinn(model, num_epochs=10000, lr=1e-3, N_interior=100, N_boundary=2):
    """
    训练PINN
    """
    optimizer = torch.optim.Adam(model.parameters(), lr=lr)
    
    # 边界点（固定）
    x_boundary = torch.tensor([[0.0], [1.0]], dtype=torch.float32)
    
    # 记录损失历史
    history = {'total': [], 'pde': [], 'bc': []}
    
    for epoch in range(num_epochs):
        # 在每个epoch随机采样内部配点
        x_interior = torch.rand(N_interior, 1)  # 均匀分布在[0,1]
        
        # 计算损失
        loss, loss_pde, loss_bc = compute_loss(model, x_interior, x_boundary)
        
        # 反向传播
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        
        # 记录
        history['total'].append(loss.item())
        history['pde'].append(loss_pde.item())
        history['bc'].append(loss_bc.item())
        
        # 打印进度
        if (epoch + 1) % 1000 == 0:
            print(f"Epoch {epoch+1:5d} | Loss: {loss.item():.2e} | "
                  f"PDE: {loss_pde.item():.2e} | BC: {loss_bc.item():.2e}")
    
    return history

# ========================
# 第五步：主程序
# ========================
if __name__ == "__main__":

\subsubsection{自动微分的使用}

最关键的部分是如何用PyTorch的自动微分计算二阶导数：

\begin{lstlisting}[language=Python, caption={自动微分计算二阶导数}]
# 第一步：计算 du/dx
u_x = torch.autograd.grad(
    outputs=u,           # 要对谁求导的"分子"
    inputs=x,            # 对谁求导的"分母"
    grad_outputs=torch.ones_like(u),  # 链式法则的上游梯度
    create_graph=True,   # 保留计算图，因为还要继续求导
    retain_graph=True    # 保留计算图供后续使用
)[0]

# 第二步：计算 d²u/dx²
u_xx = torch.autograd.grad(
    outputs=u_x,         # 现在对 u_x 求导
    inputs=x,            # 还是对 x 求导
    grad_outputs=torch.ones_like(u_x),
    create_graph=True    # 如果还需要反向传播，继续保留
)[0]
\end{lstlisting}

\begin{remark}[为什么需要create\_graph=True？]
回顾链式法则：在训练时，我们需要计算$\frac{\partial \mathcal{L}}{\partial \theta}$，而$\mathcal{L}$依赖于$u_{xx}$，$u_{xx}$又依赖于$\theta$。因此，计算$u_{xx}$的过程本身也需要被"记住"，以便后续对$\theta$求导。这就是\texttt{create\_graph=True}的作用。
\end{remark}

\subsubsection{配点采样策略}

我们在每个epoch随机采样新的配点：
\begin{lstlisting}[language=Python]
x_interior = torch.rand(N_interior, 1)  # 每次重新采样
\end{lstlisting}

这种策略称为\textbf{随机配点}（stochastic collocation），它有两个好处：
\begin{enumerate}
    \item 避免网络过拟合到特定的配点位置
    \item 相当于对整个区域的积分进行蒙特卡洛估计
\end{enumerate}

\section{硬约束与软约束：两种处理边界的哲学}
% ====================================================================================

上一节使用的方法是\textbf{软约束}（soft constraint）——通过在损失函数中加入惩罚项来"鼓励"网络满足边界条件。现在我们介绍另一种方法：\textbf{硬约束}（hard constraint）。

\subsection{软约束的优缺点}

\begin{center}
\begin{tabular}{p{6cm}|p{6cm}}
\hline
\textbf{优点} & \textbf{缺点} \\
\hline
实现简单，只需修改损失函数 & 边界条件永远只是近似满足 \\
通用性强，适用于各种边界条件 & 需要调节罚参数$\lambda$ \\
容易处理复杂几何 & 梯度竞争问题（见下节） \\
\hline
\end{tabular}
\end{center}

\subsection{硬约束：通过架构设计强制满足边界条件}

有没有办法\textbf{精确}满足边界条件，而不是近似满足？

\begin{definition}[硬约束PINN]
硬约束PINN构造一个特殊形式的解：
\begin{equation}
    u_\theta(x) = A(x) + B(x) \cdot N_\theta(x)
\end{equation}
其中：
\begin{itemize}
    \item $A(x)$是一个精确满足边界条件的"提升函数"（lift function）
    \item $B(x)$是一个在边界上为零的"距离函数"（distance function）
    \item $N_\theta(x)$是普通的神经网络，可以输出任意值
\end{itemize}
\end{definition}
\storynote{Lagaris, Likas \& Fotiadis}{1998年，三位希腊学者就用神经网络解微分方程，用的正是这里的"提升函数 + 距离函数"形式 $u = A(x) + B(x) N_\theta(x)$。当时没有自动微分框架也没有 GPU，这个想法沉睡了近二十年，直到 PINN 把它唤醒。}

\begin{example}[一维齐次边界条件]
对于$u(0) = 0, u(1) = 0$的边界条件，我们可以选择：
\begin{itemize}
    \item $A(x) = 0$（齐次边界条件不需要提升）
    \item $B(x) = x(1-x)$（在$x=0$和$x=1$处都为零）
\end{itemize}
因此：
\begin{equation}
    u_\theta(x) = x(1-x) \cdot N_\theta(x)
\end{equation}

无论$N_\theta(x)$输出什么值，我们总有：
\begin{align}
    u_\theta(0) &= 0 \cdot (1-0) \cdot N_\theta(0) = 0 \quad \checkmark \\
    u_\theta(1) &= 1 \cdot (1-1) \cdot N_\theta(1) = 0 \quad \checkmark
\end{align}
边界条件\textbf{自动精确满足}！
\end{example}

\begin{example}[一维非齐次边界条件]
如果边界条件是$u(0) = a, u(1) = b$，我们需要一个非零的提升函数：
\begin{itemize}
    \item $A(x) = a(1-x) + bx$（线性插值，满足$A(0)=a, A(1)=b$）
    \item $B(x) = x(1-x)$（同上）
\end{itemize}
因此：
\begin{equation}
    u_\theta(x) = \underbrace{a(1-x) + bx}_{\text{满足边界条件}} + \underbrace{x(1-x) \cdot N_\theta(x)}_{\text{边界上为零的修正}}
\end{equation}

验证：$u_\theta(0) = a + 0 = a$，$u_\theta(1) = b + 0 = b$。
\end{example}

    \centering
    \includegraphics[width=0.95\textwidth]{figs_chap13/constraint_concept.pdf}
    \caption{软约束与硬约束的对比示意图。左图：软约束通过惩罚项间接满足边界条件，边界可能存在误差；右图：硬约束通过结构设计（乘以$x(1-x)$因子）使边界条件自动精确满足。}
    \label{fig:constraint_concept}
\end{figure}

图\ref{fig:constraint_concept}直观展示了两种约束方式的本质区别：
\begin{itemize}
    \item \textbf{软约束}：网络直接输出预测值，通过惩罚项"告诉"网络边界应该取什么值。但这只是一种"建议"，网络可能无法完美遵守。
    \item \textbf{硬约束}：在网络输出上乘以一个"距离函数"（如$x(1-x)$），这个函数在边界处恰好为零。无论网络输出什么，最终结果在边界上都精确为零。
\end{itemize}

\subsection{硬约束PINN的代码实现}

\begin{lstlisting}[language=Python, caption={硬约束PINN的实现}]
class HardConstraintPINN(nn.Module):
    def __init__(self, layers, bc_left=0.0, bc_right=0.0):
        """
        硬约束PINN
        
        参数:
            layers: 网络层定义（与之前相同）
            bc_left: 左边界条件 u(0)
            bc_right: 右边界条件 u(1)
        """
        super().__init__()
        
        # 内部网络 N_theta
        self.net = nn.ModuleList()
        for i in range(len(layers) - 1):
            self.net.append(nn.Linear(layers[i], layers[i+1]))
        
        self.activation = torch.tanh
        self.bc_left = bc_left
        self.bc_right = bc_right
        
        # 初始化
        for layer in self.net:
            nn.init.xavier_normal_(layer.weight)
            nn.init.zeros_(layer.bias)
    
    def forward(self, x):
        # 计算内部网络的输出 N_theta(x)
        h = x
        for i, layer in enumerate(self.net[:-1]):
            h = self.activation(layer(h))
        N = self.net[-1](h)
        
        # 硬约束公式: u = A(x) + B(x) * N(x)
        # A(x) = a*(1-x) + b*x  (线性插值)
        # B(x) = x*(1-x)        (距离函数)
        
        A = self.bc_left * (1 - x) + self.bc_right * x
        B = x * (1 - x)
        
        u = A + B * N
        return u

# 使用硬约束PINN时，损失函数只需要PDE残差，不需要边界损失！
def compute_loss_hard_constraint(model, x_interior):
    """硬约束PINN的损失函数——只有PDE残差"""
    residual = compute_pde_residual(model, x_interior)
    loss_pde = torch.mean(residual ** 2)
    return loss_pde
\end{lstlisting}

\subsection{二维问题的硬约束}

\begin{example}[二维矩形区域]
考虑$\Omega = [0, 1]^2$上的齐次Dirichlet边界条件$u|_{\partial\Omega} = 0$。

距离函数可以选择：
\begin{equation}
    B(x, y) = x(1-x) \cdot y(1-y)
\end{equation}
这个函数在四条边上都为零。
\end{example}

\begin{example}[二维圆域]
\label{ex:circle}
对于圆域$\Omega = \{(x, y) : x^2 + y^2 < 1\}$上的齐次边界条件：
\begin{equation}
    B(x, y) = 1 - x^2 - y^2
\end{equation}
这个函数在圆周上$x^2 + y^2 = 1$时为零，在内部为正。
\end{example}

\begin{tcolorbox}[colback=red!5, colframe=red!50, title=硬约束的局限]
硬约束方法虽然优雅，但有几个限制：
\begin{itemize}
    \item 对于复杂几何区域（如带孔的区域、不规则边界），构造合适的距离函数$B(x)$很困难
    \item 对于Neumann边界条件（给定$\frac{\partial u}{\partial n}$），硬约束设计更加复杂
    \item 对于混合边界条件，可能需要分区域处理
\end{itemize}
\end{tcolorbox}

\section{训练的病态：为什么PINN经常失败？}
\label{sec:gradient_pathology}
% ====================================================================================

如果你已经运行了上一节的代码，你可能觉得PINN很简单。但如果尝试更复杂的问题，你很可能会遇到训练失败的情况。这一节我们来分析PINN训练困难的根本原因。

\subsection{现象一：频谱偏差}

\begin{definition}[频谱偏差]
\textbf{频谱偏差}（spectral bias）是指神经网络倾向于首先学习目标函数的低频成分，而高频成分学习得很慢甚至学不会的现象。
\end{definition}

\begin{example}[高频函数的逼近困难]
考虑函数：
\begin{equation}
    u(x) = \sin(2\pi x) + 0.1\sin(20\pi x)
\end{equation}
它包含一个低频成分$\sin(2\pi x)$（周期为1）和一个高频成分$0.1\sin(20\pi x)$（周期为0.1）。

用一个标准的MLP去拟合这个函数，你会观察到：
\begin{itemize}
    \item 前100个epoch：网络快速学会了$\sin(2\pi x)$
    \item 100-1000个epoch：高频成分$0.1\sin(20\pi x)$几乎没有进展
    \item 1000-10000个epoch：高频成分缓慢改善，但仍有明显误差
\end{itemize}
\end{example}

\begin{lstlisting}[language=Python, caption={频谱偏差的演示代码}]
import torch
import torch.nn as nn
import numpy as np
import matplotlib.pyplot as plt

# 目标函数：低频 + 高频
def target_function(x):
    return torch.sin(2 * np.pi * x) + 0.1 * torch.sin(20 * np.pi * x)

# 简单的MLP
class SimpleMLP(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(1, 64),
            nn.Tanh(),
            nn.Linear(64, 64),
            nn.Tanh(),
            nn.Linear(64, 1)
        )
    
    def forward(self, x):
        return self.net(x)

# 训练并记录不同epoch的结果
model = SimpleMLP()
optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)

x_train = torch.linspace(0, 1, 200).reshape(-1, 1)
y_train = target_function(x_train)

checkpoints = [100, 500, 1000, 5000, 10000]
results = {}

for epoch in range(10001):
    pred = model(x_train)
    loss = torch.mean((pred - y_train)**2)
    
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
    
    if epoch in checkpoints:
        with torch.no_grad():
            results[epoch] = model(x_train).numpy().flatten()
        print(f"Epoch {epoch}: Loss = {loss.item():.6f}")

# 可视化
fig, axes = plt.subplots(1, len(checkpoints), figsize=(15, 3))
x_np = x_train.numpy().flatten()
y_np = y_train.numpy().flatten()

for i, epoch in enumerate(checkpoints):
    axes[i].plot(x_np, y_np, 'b-', label='真实值', alpha=0.7)
    axes[i].plot(x_np, results[epoch], 'r--', label='预测值')
    axes[i].set_title(f'Epoch {epoch}')
    axes[i].legend()
    axes[i].grid(True, alpha=0.3)

plt.tight_layout()
plt.savefig('spectral_bias.png', dpi=150)
plt.show()
\end{lstlisting}

\end{itemize}

这个实验深刻揭示了标准MLP的固有局限：\textbf{对高频信息学习缓慢}。在PINN求解PDE时，如果真解包含高频成分（如激波、边界层、快速振荡解），标准网络会表现得很差。

\subsubsection{频谱偏差的理论解释：神经正切核}

频谱偏差可以用\textbf{神经正切核}（Neural Tangent Kernel，NTK）理论来解释。

\begin{definition}[神经正切核]
对于一个神经网络$f_\theta(x)$，神经正切核定义为：
\begin{equation}
    K(x, x') = \nabla_\theta f_\theta(x) \cdot \nabla_\theta f_\theta(x')
\end{equation}
它度量了两个输入点$x$和$x'$处的梯度相似性。
\end{definition}

在梯度下降训练中，网络函数的演化可以近似为：
\begin{equation}
    \frac{\partial f_\theta(x)}{\partial t} = -\int K(x, x') \left( f_\theta(x') - y(x') \right) dx'
\end{equation}

\begin{proposition}[频谱偏差的NTK解释]
NTK可以做谱分解：$K(x, x') = \sum_k \lambda_k \phi_k(x) \phi_k(x')$。

学习的收敛速度与特征值$\lambda_k$成正比。对于标准的全连接网络，高频成分对应的特征值$\lambda_k$很小，因此学习很慢。
\end{proposition}

\subsubsection{解决方案：傅里叶特征映射}

一个简单而有效的解决方法是在网络输入端加入\textbf{傅里叶特征}：

\begin{definition}[傅里叶特征映射]
给定输入$x \in \mathbb{R}^d$，傅里叶特征映射定义为：
\begin{equation}
    \gamma(x) = \begin{bmatrix} \sin(2\pi B x) \\ \cos(2\pi B x) \end{bmatrix} \in \mathbb{R}^{2m}
\end{equation}
其中$B \in \mathbb{R}^{m \times d}$是一个随机矩阵，每一行对应一个频率向量。
\end{definition}

\begin{lstlisting}[language=Python, caption={傅里叶特征映射的实现}]
class FourierFeatures(nn.Module):
    def __init__(self, input_dim, num_features, scale=10.0):
        """
        傅里叶特征映射
        
        参数:
            input_dim: 输入维度
            num_features: 傅里叶特征的数量
            scale: 频率的标准差（控制能学习的最高频率）
        """
        super().__init__()
        # 随机采样频率矩阵（固定，不训练）
        B = torch.randn(num_features, input_dim) * scale
        self.register_buffer('B', B)
    
    def forward(self, x):
        # x: (batch, input_dim)
        # 计算 2*pi*B*x
        x_proj = 2 * np.pi * x @ self.B.T  # (batch, num_features)
        # 返回 [sin, cos]
        return torch.cat([torch.sin(x_proj), torch.cos(x_proj)], dim=-1)

class FourierPINN(nn.Module):
    def __init__(self, input_dim, hidden_layers, num_fourier=64, scale=10.0):
        super().__init__()
        
        # 傅里叶特征层
        self.fourier = FourierFeatures(input_dim, num_fourier, scale)
        
        # MLP处理傅里叶特征
        layers = [2 * num_fourier] + hidden_layers + [1]
        self.net = nn.ModuleList()
        for i in range(len(layers) - 1):
            self.net.append(nn.Linear(layers[i], layers[i+1]))
        
        self.activation = torch.tanh
    
    def forward(self, x):
        # 先通过傅里叶特征映射
        h = self.fourier(x)
        # 再通过MLP
        for i, layer in enumerate(self.net[:-1]):
            h = self.activation(layer(h))
        return self.net[-1](h)
\end{lstlisting}

\end{tcolorbox}

\subsection{现象二：梯度竞争}
\label{subsec:gradient_conflict}

回到PINN的损失函数：
\begin{equation}
    \mathcal{L} = L_{\text{PDE}} + \lambda L_{\text{BC}}
\end{equation}

在优化过程中，参数更新方向为：
\begin{equation}
    \Delta \theta \propto -\nabla_\theta \mathcal{L} = -\nabla_\theta L_{\text{PDE}} - \lambda \nabla_\theta L_{\text{BC}}
\end{equation}

\begin{definition}[梯度竞争]
\textbf{梯度竞争}（gradient pathology/conflict）是指多个损失项的梯度方向冲突，导致优化困难的现象。

具体地，如果：
\begin{equation}
    \nabla_\theta L_{\text{PDE}} \cdot \nabla_\theta L_{\text{BC}} < 0
\end{equation}
即两个梯度的夹角大于90°，那么一个任务的优化会损害另一个任务。
\end{definition}
\think{梯度竞争的本质是"目标"和"约束"在参数空间抢方向。第1章的 KKT 条件 $\nabla f + \lambda \nabla g = 0$ 恰恰说：在最优点两者的梯度必须共线反向。所以夹角大于 $90^\circ$ 不是 bug，而是"还没到最优点"的信号——问题在于固定的 $\lambda$ 永远没法让它们恰好抵消。}

\subsubsection{诊断梯度竞争}

\begin{lstlisting}[language=Python, caption={诊断梯度竞争}]
def diagnose_gradient_conflict(model, x_interior, x_boundary):
    """
    诊断梯度竞争
    
    返回:
        cos_angle: 两个梯度的夹角余弦值
        grad_ratio: 梯度范数的比值
    """
    # 计算PDE损失的梯度
    model.zero_grad()
    residual = compute_pde_residual(model, x_interior)
    loss_pde = torch.mean(residual ** 2)
    loss_pde.backward(retain_graph=True)
    
    grad_pde = torch.cat([p.grad.flatten() for p in model.parameters()])
    
    # 计算BC损失的梯度
    model.zero_grad()
    u_boundary = model(x_boundary)
    loss_bc = torch.mean(u_boundary ** 2)
    loss_bc.backward()
    
    grad_bc = torch.cat([p.grad.flatten() for p in model.parameters()])
    
    # 计算夹角余弦
    cos_angle = torch.dot(grad_pde, grad_bc) / (grad_pde.norm() * grad_bc.norm() + 1e-8)
    
    # 计算梯度范数比值
    grad_ratio = grad_pde.norm() / (grad_bc.norm() + 1e-8)
    
    return cos_angle.item(), grad_ratio.item()

# 在训练过程中监控
for epoch in range(num_epochs):
    # ... 正常训练代码 ...
    
    if epoch % 100 == 0:
        cos_angle, grad_ratio = diagnose_gradient_conflict(model, x_interior, x_boundary)
        print(f"Epoch {epoch}: cos(angle) = {cos_angle:.3f}, |grad_pde|/|grad_bc| = {grad_ratio:.3f}")
        
        if cos_angle < -0.5:
            print("  警告：存在严重的梯度竞争！")
\end{lstlisting}

我们在训练过程中监控了PDE损失和边界损失各自产生的梯度，并计算它们的夹角余弦值和范数比值。

从图\ref{fig:gradient_diagnosis}中，我们可以观察到以下现象：

\textbf{1. 梯度冲突频繁发生}。在100个采样点中，有42次（42\%）出现了负的梯度夹角余弦值，即$\nabla L_{\text{PDE}} \cdot \nabla L_{\text{BC}} < 0$。这意味着\textbf{将近一半的训练步骤中，优化一个目标会损害另一个目标}。

\textbf{2. 梯度范数不平衡}。PDE梯度的范数通常比BC梯度大1-2个数量级。这说明在使用固定权重$\lambda=100$时，两个任务的梯度贡献是不均衡的。

\textbf{3. 训练不稳定性}。损失曲线中的锯齿状波动正是梯度竞争的直接反映——当PDE损失下降时，BC损失可能上升，反之亦然。

\subsubsection{梯度竞争的后果}

当梯度竞争严重时，你可能观察到：
\begin{itemize}
    \item 损失震荡：$L_{\text{PDE}}$下降时$L_{\text{BC}}$上升，反之亦然
    \item 收敛极慢：优化器在两个任务之间"犹豫不决"
    \item 收敛到错误的解：某个任务被完全牺牲
\end{itemize}

\begin{tcolorbox}[colback=red!5, colframe=red!50, title=梯度竞争是PINN的核心困难]
梯度竞争不仅存在于PDE损失和BC损失之间，在时间演化问题中还存在于不同时刻的损失之间。这是PINN在复杂问题上经常失败的根本原因之一。下一节我们将介绍如何通过自适应加权来缓解这个问题。
\end{tcolorbox}

\section{拉格朗日对偶视角与自适应加权}
% ====================================================================================

\subsection{从罚函数到拉格朗日乘子}

回顾罚函数法的局限：权重$\lambda$是固定的，无法自适应地平衡不同约束。

让我们回归更一般的\textbf{拉格朗日对偶}框架。将PINN问题写成：
\begin{equation}
    \min_\theta L_{\text{PDE}}(\theta) \quad \text{s.t.} \quad L_{\text{BC}}(\theta) = 0
\end{equation}

拉格朗日函数为：
\begin{equation}
    \mathcal{L}(\theta, \lambda) = L_{\text{PDE}}(\theta) + \lambda L_{\text{BC}}(\theta)
\end{equation}

\begin{definition}[对偶上升法]
对偶上升法（Dual Ascent）交替更新原始变量和对偶变量：
\begin{align}
    \theta^{k+1} &= \arg\min_\theta \mathcal{L}(\theta, \lambda^k) \quad \text{（原始更新）} \\
    \lambda^{k+1} &= \lambda^k + \eta_\lambda \cdot L_{\text{BC}}(\theta^{k+1}) \quad \text{（对偶更新，$\eta_\lambda$ 是对偶步长）}
\end{align}
\end{definition}
\review{第2章}{对偶上升不是新东西：第2章的对偶函数 $d(\lambda) = \min_\theta \mathcal{L}(\theta, \lambda)$ 满足 $\partial d/\partial \lambda = g(\theta^*)$，所以 $\lambda \leftarrow \lambda + \eta\, g$ 就是沿对偶函数爬山。第10章用同一招求最短路。}
\clarify{一个数学上的细节：$L_{\mathrm{BC}}$ 是残差的\textbf{平方和}，把它当成单条约束时，可行点处 $\nabla L_{\mathrm{BC}} = 0$，乘子会退化；而且对偶更新的增量正比于残差的平方，残差一小乘子就"冻住"。更规范的做法是逐点约束 $r_j = 0$、逐点带符号更新 $\lambda_j \leftarrow \lambda_j + \eta\, r_j$——这也和前面的乘子函数 $\mu(x)$ 自洽。}

\begin{tcolorbox}[colback=green!5, colframe=green!50, title=关键洞察]
对偶更新$\lambda^{k+1} = \lambda^k + \eta_\lambda \cdot L_{\text{BC}}(\theta^{k+1})$的直觉：
\begin{itemize}
    \item 如果边界条件没被满足好（$L_{\text{BC}}$大），就增大$\lambda$，加强惩罚
    \item 如果已经满足得很好（$L_{\text{BC}}$小），$\lambda$就保持稳定
\end{itemize}
这给了我们一个\textbf{自适应调整权重}的方法！
\end{tcolorbox}

\subsection{实用算法：自适应权重PINN}

\begin{lstlisting}[language=Python, caption={自适应权重PINN的实现}]
class AdaptiveWeightPINN:
    def __init__(self, model, lr_model=1e-3, lr_lambda=1e-2, rho=1.0):
        """
        自适应权重PINN
        
        使用拉格朗日对偶方法自动调整边界条件的权重
        """
        self.model = model
        self.optimizer = torch.optim.Adam(model.parameters(), lr=lr_model)
        
        # 拉格朗日乘子（可学习）
        self.lambda_bc = torch.tensor([1.0], requires_grad=False)
        self.lr_lambda = lr_lambda
        self.rho = rho
    
    def train_step(self, x_interior, x_boundary):
        # 计算损失
        residual = compute_pde_residual(self.model, x_interior)
        loss_pde = torch.mean(residual ** 2)
        
        u_boundary = self.model(x_boundary)
        loss_bc = torch.mean(u_boundary ** 2)
        
        # 增广拉格朗日
        total_loss = loss_pde + self.lambda_bc * loss_bc + self.rho / 2 * loss_bc ** 2
        
        # 更新网络参数（原始更新）
        self.optimizer.zero_grad()
        total_loss.backward()
        self.optimizer.step()
        
        # 更新拉格朗日乘子（对偶更新）
        with torch.no_grad():
            self.lambda_bc += self.lr_lambda * loss_bc
            self.lambda_bc = torch.clamp(self.lambda_bc, min=0.0)  # 保证非负
        
        return loss_pde.item(), loss_bc.item(), self.lambda_bc.item()
    
    def train(self, num_epochs, N_interior=100):
        x_boundary = torch.tensor([[0.0], [1.0]])
        history = {'pde': [], 'bc': [], 'lambda': []}
        
        for epoch in range(num_epochs):
            x_interior = torch.rand(N_interior, 1)
            loss_pde, loss_bc, lam = self.train_step(x_interior, x_boundary)
            
            history['pde'].append(loss_pde)
            history['bc'].append(loss_bc)
            history['lambda'].append(lam)
            
            if (epoch + 1) % 1000 == 0:
                print(f"Epoch {epoch+1}: PDE={loss_pde:.2e}, BC={loss_bc:.2e}, λ={lam:.2f}")
        
        return history

# 使用示例
model = PINN([1, 50, 50, 50, 1])
trainer = AdaptiveWeightPINN(model, lr_model=1e-3, lr_lambda=0.1, rho=10.0)
history = trainer.train(num_epochs=10000)
\end{lstlisting}

\subsection{GradNorm：基于梯度的自适应加权}

另一种流行的方法是\textbf{GradNorm}，它的目标是让所有任务的梯度范数趋于一致。

\begin{definition}[GradNorm目标]
设$w_i$是第$i$个任务的权重，$g_i = |w_i \nabla_\theta L_i|$是加权后的梯度范数。GradNorm的目标是：
\begin{equation}
    g_i \approx \bar{g} \cdot r_i^{-\alpha} \quad \forall i
\end{equation}
其中$\bar{g}$是平均梯度范数，$r_i = L_i / L_i^{(0)}$是任务$i$的相对损失（相对于初始损失），$\alpha$是超参数（通常取1.5）。
\end{definition}

\begin{framed}
\textbf{GradNorm算法伪代码}

\texttt{初始化:} 权重 $w_i = 1$，记录初始损失 $L_i^{(0)}$

\texttt{for} 每个训练步 \texttt{do}:
\begin{enumerate}[label=\arabic*., leftmargin=2em]
    \item 计算各任务损失 $L_{\text{pde}}, L_{\text{bc}}$
    \item 计算各任务的加权梯度范数 $G_i = w_i \|\nabla_W L_i\|$
    \item 计算平均梯度范数 $\bar{G} = \frac{1}{n}\sum_i G_i$
    \item 计算相对损失 $r_i = L_i / L_i^{(0)}$
    \item 计算目标梯度范数 $G_i^{\text{target}} = \bar{G} \cdot (r_i / \bar{r})^\alpha$
    \item 更新权重以最小化 $\sum_i |G_i - G_i^{\text{target}}|$
    \item 归一化权重使 $\sum_i w_i = n$
    \item 用加权损失 $\sum_i w_i L_i$ 更新网络参数
\end{enumerate}
\texttt{end for}
\end{framed}

GradNorm的核心思想是：让学习\textbf{慢}的任务（损失下降慢，梯度相对小）获得更大的权重，让学习\textbf{快}的任务权重降低，从而平衡多个任务的学习速度。

\begin{remark}
GradNorm需要在每步计算多个任务的梯度范数，计算开销较大。在实践中，前面介绍的拉格朗日对偶方法通常是更简单有效的选择。我们在自适应权重实验（图\ref{fig:adaptive_weight}）中已经验证了其效果。
\end{remark}

\section{时间演化方程的特殊困难：因果性}
% ====================================================================================

\subsection{问题的特殊性}

考虑热方程：
\begin{equation}
    \frac{\partial u}{\partial t} = \alpha \frac{\partial^2 u}{\partial x^2}, \quad (x, t) \in (0, 1) \times (0, T)
\end{equation}
\begin{equation}
    u(x, 0) = u_0(x) \quad \text{（初始条件）}
\end{equation}
\begin{equation}
    u(0, t) = u(1, t) = 0 \quad \text{（边界条件）}
\end{equation}

传统数值方法是\textbf{时间步进}的：
\begin{enumerate}
    \item 先算$t = \Delta t$时刻的解
    \item 再算$t = 2\Delta t$时刻的解
    \item 依次推进...
\end{enumerate}

这自然地尊重了\textbf{因果律}——未来依赖于过去，不能反过来。

\subsection{标准PINN的问题}

标准PINN怎么做？在整个时空域$(x, t) \in [0, 1] \times [0, T]$上\textbf{同时}采样配点，一起训练。

\begin{lstlisting}[language=Python, caption={标准PINN处理热方程（有问题的版本）}]
# 采样配点：在整个时空域上同时采样
x = torch.rand(N, 1)  # 空间坐标
t = torch.rand(N, 1) * T  # 时间坐标，从0到T均匀采样
xt = torch.cat([x, t], dim=1)

# 计算PDE残差
u = model(xt)
u_t = grad(u, t)
u_xx = grad(grad(u, x), x)
residual = u_t - alpha * u_xx

# 同时训练所有时刻
loss = torch.mean(residual ** 2) + lambda_ic * loss_ic + lambda_bc * loss_bc
\end{lstlisting}

\textbf{问题}：网络在同时学习所有时刻，但它没有"先把$t=0$学好，再学$t=\Delta t$"的机制。初始时刻的误差会传播到后续时刻，而网络对此毫无感知。

\textbf{结果}：误差随时间累积，长时间预测严重失准。

\subsection{解决方案：因果训练}

\textbf{因果训练}（Causal Training）的思路是：引入一个时间权重函数$w(t)$，使得网络\textbf{优先}学习早期时刻。

\begin{definition}[因果权重函数]
定义因果权重：
\begin{equation}
    w(t) = \exp\left( -\epsilon \int_0^t L_r(s) \, ds \right), \qquad L_r(s) = \frac{1}{N_x}\sum_i |r(x_i, s)|^2
\end{equation}
其中$r(x, t)$是PDE残差，$L_r(s)$是 $s$ 时刻的空间平均残差，$\epsilon > 0$是控制因果性强度的参数。
\end{definition}

\textbf{直觉}：只有当$t' < t$时刻的残差足够小，$t$时刻的权重$w(t)$才会接近1。

在离散形式下，可以简化为\textbf{分段训练}（time-marching）：

\begin{framed}
\textbf{因果PINN分段训练算法}

\texttt{输入:} 总时间$T$，窗口数$K$，每窗口训练轮数$E$

划分时间窗口: $[0, \Delta t], [\Delta t, 2\Delta t], \ldots, [(K-1)\Delta t, T]$，其中$\Delta t = T/K$

\texttt{for} $k = 0, 1, \ldots, K-1$ \texttt{do}: \hfill {\small // 依次处理每个时间窗口}
\begin{enumerate}[label=(\alph*), leftmargin=2em]
    \item 当前窗口: $t \in [k\Delta t, (k+1)\Delta t]$
    \item \texttt{for} $e = 1, \ldots, E$ \texttt{do}: \hfill {\small // 在当前窗口训练$E$轮}
    \begin{itemize}[leftmargin=1em]
        \item 在当前窗口内随机采样配点
        \item 计算PDE残差损失
        \item \texttt{if} $k = 0$: 添加初始条件损失（$t=0$时刻）
        \item \texttt{else}: 添加连续性损失（与上一窗口终点衔接）
        \item 梯度下降更新网络参数
    \end{itemize}
    \item 存储当前窗口终点的解，供下一窗口使用
\end{enumerate}
\texttt{end for}
\end{framed}

\textbf{关键思想}：先把$t \in [0, \Delta t]$学好，再学$[\Delta t, 2\Delta t]$，以此类推。这样初始条件的信息可以"逐步传递"到后续时刻，避免了标准PINN中各时刻相互干扰的问题。

\begin{remark}
因果训练在长时间演化问题（如$t \in [0, 100]$）中特别有效。标准PINN可能完全失效（误差累积爆炸），而因果PINN通过分段学习保持了预测精度。感兴趣的读者可以参考Wang等人2022年的工作\textit{"Respecting causality is all you need for training physics-informed neural networks"}。
\end{remark}

对比标准PINN和因果PINN在求解热方程时的表现：
\begin{enumerate}
    \item $t \in [0, 1]$的短时间预测
    \item $t \in [0, 10]$的长时间预测
\end{enumerate}
哪种方法在长时间预测上更准确？
\end{exercise}

\section{变分视角：Deep Ritz Method}
% ====================================================================================

到目前为止，我们都在最小化\textbf{PDE残差}。但还有另一条路——最小化\textbf{能量泛函}。

\subsection{从残差最小化到能量最小化}

回顾泊松方程：
\begin{equation}
    -\nabla^2 u = f, \quad u|_{\partial\Omega} = 0
\end{equation}

这个方程等价于最小化能量泛函：
\begin{equation}
    J[u] = \frac{1}{2}\int_\Omega |\nabla u|^2 \, dx - \int_\Omega f \cdot u \, dx
\end{equation}

\begin{theorem}[能量原理]
$u$是泊松方程的解，当且仅当$u$是能量泛函$J[u]$的极小点。
\end{theorem}
\review{第5章}{"有限元 = 能量最小化"：第5章证明了 $KU = F$ 是 $\min_U \frac{1}{2}U^\top KU - F^\top U$ 的一阶条件，而这个二次型正是 $J[u]$ 在有限元基下的离散版本。Deep Ritz 只是把基函数换成了神经网络。}

\begin{proof}
对$J[u]$求变分。设$v$是任意满足$v|_{\partial\Omega} = 0$的函数，考虑：
\begin{equation}
    \frac{d}{d\epsilon}\bigg|_{\epsilon=0} J[u + \epsilon v] = 0
\end{equation}

计算：
\begin{align}
    J[u + \epsilon v] &= \frac{1}{2}\int_\Omega |\nabla u + \epsilon \nabla v|^2 \, dx - \int_\Omega f(u + \epsilon v) \, dx \\
    &= J[u] + \epsilon \left( \int_\Omega \nabla u \cdot \nabla v \, dx - \int_\Omega fv \, dx \right) + O(\epsilon^2)
\end{align}

因此：
\begin{equation}
    \delta J = \int_\Omega \nabla u \cdot \nabla v \, dx - \int_\Omega fv \, dx = 0
\end{equation}

利用分部积分（格林第一公式）：
\begin{equation}
    \int_\Omega \nabla u \cdot \nabla v \, dx = -\int_\Omega (\nabla^2 u) v \, dx + \underbrace{\int_{\partial\Omega} \frac{\partial u}{\partial n} v \, ds}_{= 0 \text{ （因为 } v|_{\partial\Omega} = 0\text{）}}
\end{equation}

代入得：
\begin{equation}
    \delta J = \int_\Omega (-\nabla^2 u - f) v \, dx = 0
\end{equation}

由$v$的任意性，$-\nabla^2 u = f$。
\end{proof}

\subsection{Deep Ritz Method}

\textbf{Deep Ritz Method}的想法是：不最小化残差$|{-\nabla^2 u - f}|^2$，而是最小化能量泛函$J[u_\theta]$。

\begin{equation}
    \mathcal{L}_{\text{Ritz}}(\theta) = \underbrace{\frac{1}{N}\sum_{i=1}^{N} \left( \frac{1}{2}|\nabla u_\theta(x_i)|^2 - f(x_i) u_\theta(x_i) \right)}_{\text{能量的蒙特卡洛估计}} + \underbrace{\lambda \cdot \frac{1}{M}\sum_{j=1}^{M} |u_\theta(x_j^b)|^2}_{\text{边界惩罚}}
\end{equation}

\begin{lstlisting}[language=Python, caption={Deep Ritz Method的实现}]
def compute_ritz_loss(model, x_interior, x_boundary, f_func, lambda_bc=100.0):
    """
    Deep Ritz Method的损失函数
    """
    # 内部点
    x = x_interior.requires_grad_(True)
    u = model(x)
    
    # 计算梯度 ∇u
    grad_u = torch.autograd.grad(
        outputs=u,
        inputs=x,
        grad_outputs=torch.ones_like(u),
        create_graph=True
    )[0]
    
    # 能量泛函: (1/2)|∇u|² - f·u
    f = f_func(x)
    energy = 0.5 * torch.sum(grad_u ** 2, dim=1) - f.squeeze() * u.squeeze()
    loss_energy = torch.mean(energy)
    
    # 边界条件
    u_boundary = model(x_boundary)
    loss_bc = torch.mean(u_boundary ** 2)
    
    total_loss = loss_energy + lambda_bc * loss_bc
    
    return total_loss, loss_energy, loss_bc
\end{lstlisting}

\section{逆问题与物理发现}
% ====================================================================================

\subsection{正问题与逆问题}

到目前为止，我们讨论的都是\textbf{正问题}：已知方程（包括所有参数），求解。

\textbf{逆问题}则反过来：已知（部分）解的观测数据，反推方程中的未知参数。

\begin{example}[热扩散系数反演]
考虑带未知扩散系数的热方程：
\begin{equation}
    \frac{\partial u}{\partial t} = D \frac{\partial^2 u}{\partial x^2}
\end{equation}

我们在某些点$(x_i, t_i)$测量了$u$的值$u_i^{\text{obs}}$，想要反推扩散系数$D$。

这在实际中很常见：材料的热扩散系数往往需要通过实验测定。
\end{example}

\subsection{PINN求解逆问题}

PINN天然适合逆问题！只需将$D$也作为可学习参数：

\begin{equation}
    \mathcal{L}(\theta, D) = \underbrace{\sum_i |u_\theta(x_i, t_i) - u_i^{\text{obs}}|^2}_{L_{\text{data}}：\text{拟合观测数据}} + \underbrace{\lambda \sum_j |r_D(x_j, t_j)|^2}_{L_{\text{PDE}}：\text{PDE残差}}
\end{equation}

其中残差$r_D = \partial_t u_\theta - D \partial_{xx} u_\theta$依赖于待定参数$D$。

同时优化$\theta$和$D$，最终得到：
\begin{itemize}
    \item 网络$u_\theta$逼近真实解
    \item 参数$D$收敛到真实扩散系数
\end{itemize}

\begin{lstlisting}[language=Python, caption={PINN求解逆问题}]
class InversePINN(nn.Module):
    def __init__(self, layers):
        super().__init__()
        
        # 神经网络逼近u
        self.net = PINN(layers)
        
        # 未知物理参数（可学习）
        self.D = nn.Parameter(torch.tensor([0.5]))  # 初始猜测
    
    def forward(self, x, t):
        xt = torch.cat([x, t], dim=1)
        return self.net(xt)

def train_inverse_pinn(model, x_obs, t_obs, u_obs, num_epochs=10000):
    """
    训练逆问题PINN
    
    参数:
        x_obs, t_obs: 观测点的坐标
        u_obs: 观测值
    """
    optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)
    
    D_history = []
    
    for epoch in range(num_epochs):
        # 数据拟合损失
        u_pred = model(x_obs, t_obs)
        loss_data = torch.mean((u_pred - u_obs) ** 2)
        
        # PDE残差损失
        x_coll = torch.rand(200, 1, requires_grad=True)
        t_coll = torch.rand(200, 1, requires_grad=True)
        
        u = model(x_coll, t_coll)
        
        u_t = torch.autograd.grad(u, t_coll, torch.ones_like(u), create_graph=True)[0]
        u_x = torch.autograd.grad(u, x_coll, torch.ones_like(u), create_graph=True)[0]
        u_xx = torch.autograd.grad(u_x, x_coll, torch.ones_like(u_x), create_graph=True)[0]
        
        # PDE残差: u_t - D * u_xx
        residual = u_t - model.D * u_xx
        loss_pde = torch.mean(residual ** 2)
        
        # 总损失
        loss = loss_data + loss_pde
        
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        
        D_history.append(model.D.item())
        
        if (epoch + 1) % 1000 == 0:
            print(f"Epoch {epoch+1}: Loss = {loss.item():.2e}, D = {model.D.item():.4f}")
    
    return D_history

# 使用示例
# 假设真实 D = 0.1
D_true = 0.1

# 生成合成观测数据（实际应用中来自实验）
# ...

# 训练
model = InversePINN([2, 50, 50, 50, 1])
D_history = train_inverse_pinn(model, x_obs, t_obs, u_obs)

print(f"\n真实D = {D_true}, 估计D = {model.D.item():.4f}")
\end{lstlisting}

\subsection{问题设定}

考虑二维泊松方程：
\begin{equation}
    -\nabla^2 u = -\frac{\partial^2 u}{\partial x^2} - \frac{\partial^2 u}{\partial y^2} = 2\pi^2 \sin(\pi x)\sin(\pi y), \quad (x, y) \in (0, 1)^2
\end{equation}
\begin{equation}
    u = 0, \quad (x, y) \in \partial[0, 1]^2 \quad \text{（四条边界上）}

这个方程的解析解为：
\begin{equation}

\section{本章小结}
% ====================================================================================

本章我们从约束优化的视角系统地介绍了物理信息神经网络（PINN）。

\subsection{核心知识点}

\begin{enumerate}
    \item \textbf{PINN的数学本质}：将PDE求解问题转化为约束优化问题
    \begin{itemize}
        \item 软约束：罚函数法，通过损失函数惩罚约束违反
        \item 硬约束：架构设计，通过网络结构强制满足边界条件
    \end{itemize}
    
    \item \textbf{训练困难的根源}
    \begin{itemize}
        \item 频谱偏差：神经网络倾向于学习低频，解决方案是傅里叶特征
        \item 梯度竞争：多个损失项方向冲突，解决方案是自适应加权
        \item 因果性：时间演化问题需要尊重因果律，解决方案是因果训练
    \end{itemize}
    
    \item \textbf{拉格朗日对偶视角}
    \begin{itemize}
        \item 罚函数法是拉格朗日乘子法的近似（$\rho \to \infty$ 的极限，第1章视角三）
        \item 对偶上升法提供自适应调整权重的机制
    \end{itemize}
    
    \item \textbf{变分视角（Deep Ritz Method）}
    \begin{itemize}
        \item 最小化能量泛函而非PDE残差
        \item 降低导数阶数，更适合高维问题
    \end{itemize}
    
    \item \textbf{逆问题}
    \begin{itemize}
        \item PINN可以同时求解正问题和反演物理参数
        \item 将未知参数作为可学习变量
    \end{itemize}
\end{enumerate}

\begin{physicalmeaning}
\textbf{$\lambda$ 在本章的意义}：$\lambda_j$ 是"在边界点 $x_j$ 把边界条件放松一点，PDE 残差能降多少"——边界条件的影子价格。它大，说明网络正被边界条件"卡住"，PDE 和边界在抢梯度；它趋于零，说明边界已不是瓶颈。固定权重 PINN 看不到这个价格，只能靠人猜一个 $\rho$；对偶上升让 $\lambda$ 自己涨到该有的大小；硬约束则用第1章"代入消元"的办法把边界约束干脆消掉，于是 $\lambda$ 不再需要。
\begin{itemize}
    \item \textbf{第1章（拉格朗日乘子法）}：软约束就是视角三的罚函数法，硬约束就是代入消元
    \item \textbf{第3章（变分法）与第5章（有限元）}：Deep Ritz 直接最小化能量泛函，只是把帐篷函数换成了神经网络
    \item \textbf{第5章扩展阅读（条件数）}：PINN 的训练困难与优化问题的条件数密切相关
    \item \textbf{第9章}：PINN 把自动微分反过来用——对输入坐标而不是参数求导
    \item \textbf{往后看第14章}：把"对每一个点的方程约束放松一个单位"的影子价格整张表学出来，那就是格林函数
\end{itemize}
\end{physicalmeaning}
